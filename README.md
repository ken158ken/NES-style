## 📱 手機遊玩（卡比之星）

手機瀏覽器直接開 **<https://ken158ken.github.io/NES-style/卡比之星/>** 就能玩，畫面會自動縮放並顯示觸控虛擬按鍵。

- **iOS（Safari）**：開啟網址 → 點下方「分享」 → **加入主畫面** → 從主畫面圖示啟動（全螢幕、無網址列）。
- **Android（Chrome）**：開啟網址 → 右上角選單 → **安裝應用程式／加到主畫面**（或直接點瀏覽器跳出的安裝提示）。
- **建議橫向拿**（橫向時遊戲畫面置中、按鍵分佈在左右兩側；直向則畫面靠上、按鍵在下方）。
- 觸控配置：左手 **D-pad**（可滑動切換方向）、右手 **A 跳 ／ B 攻擊 ／ C 丟能力**，另有 **▶ 暫停** 與 **全螢幕**；在「設定」裡可切換左右手、按鍵大小與透明度。
- **加到主畫面後可離線遊玩**（Service Worker 會把遊戲全部檔案快取起來；有網路時自動更新到最新版）。

詳細說明見 [卡比之星/說明.md](卡比之星/說明.md)。

本機執行：在各子資料夾用 `python3 -m http.server` 後開啟 `index.html`，或直接打開 `卡比之星/dist/卡比之星.html`（單檔版）。
