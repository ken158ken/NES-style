# 紅白機遊戲開發（研究與開發基地）

> 與 `../卡比之星` 平行的獨立專案。目標：先完成 **紅白機（NES / Famicom）與掌機（GB / GBC / GBA）像素風遊戲**的全面研究，
> 再據此開發原創的電子音樂像素風遊戲（可在瀏覽器、或以真實 ROM 在 VBA / mGBA / Mesen 等模擬器執行）。

## 目錄
- `docs/research/` — 研究文件（Markdown，繁體中文，附來源網址）
  - `01_硬體規格與限制.md` — 6502 / PPU / APU / 記憶體 / mapper 與對設計的影響
  - `02_遊戲名錄與類型.md`、`02b_年表與里程碑.md` — 各類型代表作、機制亮點、年表
  - `03_經典遊戲深度解析/` — 每款一檔：關卡結構、機制、敵人 / 魔王、難度曲線、操作手感、祕密
  - `04_遊戲設計模式.md` — 關卡 / 敵人 / 魔王 / 道具 / 祕密 / 難度 / 手感 / UI / 存檔密碼
  - `05_美術與像素規範.md` — 磁磚重用、調色盤技巧、動畫幀數、假視差、閃爍
  - `06_音樂音效_2A03與chiptune.md` — 聲道、作曲技法、名曲分析、Web Audio 合成、GB / GBA 差異
  - `07_掌機_GB_GBC_GBA_規格與差異.md`
  - `08_開發工具鏈與模擬器.md` — cc65 / ca65 / NESmaker / GBDK / GB Studio / Butano、Mesen / mGBA / VBA
  - `09_法律與原創原則.md`
  - `10_專案提案.md` — 依研究提出 3 個可做的原創遊戲方案與技術路線
- `index.html` — 由上述 md 編譯的單頁總覽（可離線開啟）
- `docs/PROGRESS.md` — 研究進度（各 agent 追加）

## 原則
- 所有內容以繁體中文撰寫，引用要附網址（Wikipedia / NESdev Wiki / 官方 / 開發者訪談）。
- 區分「事實（有來源）」與「推論 / 建議」。
- 未來開發的美術、音樂、關卡一律原創，不使用任何版權 ROM / 圖片 / 音訊。
