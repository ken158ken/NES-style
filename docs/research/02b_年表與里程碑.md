# 02b 年表與里程碑（1983–1995 與其後）

## 摘要（10 行內）

1. Famicom 於 **1983-07-15** 在日本發售，售價 **14,800 日圓**，首發三款：《Donkey Kong》《Donkey Kong Jr.》《Popeye》。[源]
2. NES 於 **1985-10-18** 在紐約試賣（17 款首發陣容），**1986-09-27** 於北美全面上市；歐洲自 **1986-09-01**（北歐）起陸續登場。[源]
3. 全球主機銷量 **61.91 百萬台**；官方授權遊戲共 **1,370 款**（日本 1,062 / 北美 675 / PAL 347）。[源]
4. **1986-02-21** Famicom Disk System 發售（¥15,000，磁碟 112KB，多一路 wavetable 音源），累計約 **440 萬台**，1990 年停產。[源]
5. 關鍵技術轉折：**1986** 電池存檔（Zelda）、**1988** MMC3 + scanline IRQ（SMB3）、**1989** VRC6 擴充音源（悪魔城伝説）、**1992–93** 晚期技術巔峰（Recca、Gimmick!、Kirby's Adventure）。[源]
6. **1988-02-10**《Dragon Quest III》首日破百萬套，引發翹課購買與約 300 人被捕的社會事件（「Dragon Quest 法」實為都市傳說）。[源]
7. 銷售冠軍 *Super Mario Bros.*（40,240,000）；非同捆冠軍 *Super Mario Bros. 3*（18,000,000）。[源]
8. 最後的官方授權作品：日本 **《高橋名人の冒険島IV》1994-06-24**；北美 **《Wario's Woods》1994-12-10**；PAL 區 **《The Lion King》1995-05-25**。[源]
9. 主機停產：北美 / 歐洲 **1995-08-14**；日本 Famicom **2003-09-25**（服役 20 年）。[源]
10. NES 並未真正結束：2010 年後的 homebrew 場景（Micro Mages 等）、Evercade 合輯、NES Classic Edition 與 Nintendo Switch Online 構成了它的第二生命。[源]

## 年表：1983–1995 逐年

> 每年分「硬體 / 商業事件」與「代表作」兩部分。年份為**首發地區的首發年**；跨區作品另註。

### 1983

**硬體 / 商業事件**

| 日期 | 事件 |
|---|---|
| 1983-07-15 | **Famicom（ファミリーコンピュータ）在日本發售**，售價 ¥14,800。首發三款卡帶：《Donkey Kong》《Donkey Kong Jr.》《Popeye》。[源] |
| 1983 下半 | 發售後不久大量回報主機當機，Nintendo **全機回收更換主機板**（faulty chip）。[源] |

### 從銷量榜讀出的三個結論 [推論]

1. **前 20 名有 17 款由任天堂發行**。第三方在 NES 上的天花板遠低於任天堂，*TMNT*（4,000,000）是唯一衝進前 12 的第三方作品。

3. **日本與北美的暢銷結構完全不同**：日本榜由 RPG（DQ 系列）與棒球 / 麻將支撐，北美榜由平台動作與運動支撐。同一台主機在兩地是兩種文化商品。

### PAL 專屬 / 歐洲特有現象 [推論 + 源]

- **The Lion King（1995-05-25）是 PAL 獨佔的最後一款授權 NES 遊戲**，北美從未發行。[源]
- 歐洲各國由**不同代理商**發行（Mattel、Bergsala、Nintendo of Europe 等），導致同一款遊戲有多種盒裝與版本編號，收藏難度極高。
- **50Hz PAL 版遊戲普遍變慢**，多數開發商未針對 PAL 重新調整速度與音樂 —— 這使得許多歐洲玩家的「童年記憶速度」與日 / 美玩家不同。
- 北歐（Scandinavia）是歐洲最早上市的區域（1986-09-01），也因此 *Gimmick!* 這類日本晚期作品在北歐有正式 PAL 版（NES-JLROM / FME-7，**無擴充音源**）。[源]

### B. Micro Mages 的 40KB 技術（值得單獨學習）

Morphcat 在 2018-09-05 公開 YouTube 影片《How we fit an NES game into 40 Kilobytes》，是本作在技術圈爆紅的主因。具體手法：[源：Hackaday / NESdev 論壇]

1. **Tile 重用 + PPU 內建的水平 / 垂直翻轉屬性位元** —— 一份圖資當四份用。
2. **Metasprite 拼接 + 刻意縮小角色**（故名 "Micro" Mages）—— 為的是在 **4 人同屏時不觸發每掃描線 8 sprite 的上限**。
3. **關卡壓縮到極致**：生成全遊戲所有地圖的 tile 調色盤**只佔 60 bytes**。
4. **以鏡像（mirroring）與 tile 水平位移**，從極小的 tile set 生出多樣化場景。
5. **32KB 給程式碼、8KB 給全部圖形**，每個 byte 都要排優先序。

> [推論] Micro Mages 選 NROM 而非 UNROM / MMC3，除了技術挑戰外，也大幅降低實體卡帶的 PCB 成本與製造複雜度。

## 技術里程碑一覽（給開發者的速查）

| 年 | 技術事件 | 對設計的意義 [推論] |
|---|---|---|
| 1983 | NROM：32KB PRG + 8KB CHR，**無 bank switching** | 一切從 40KB 開始。*Micro Mages*（2019）證明這個預算至今仍夠做出完整遊戲。 |
| 1984 | Family BASIC：**首片電池備援卡帶**（2KB） | 非揮發性儲存進入家用機。 |
| 1985 | 10NES 鎖片 + 授權制度 | 平台治理的開端，也是非授權生態的起點。 |
| 1986 | FDS：112KB 磁碟 + **1 路 wavetable 擴充音源** + 可寫入存檔 | 首次有「大容量 + 可存檔 + 更多聲道」；日本的 Zelda / Metroid / Castlevania 都誕生於此。 |
| 1987 | **電池 SRAM 8KB 成為標準**（$6000–$7FFF） | RPG 與探索類型得以在西方成立。全 NES 僅約 **11.6%** 的授權遊戲有電池。[源] |
| 1987 | MMC2（mapper 9）：**PPU 讀到特定 tile 時自動切 CHR bank** | 為 *Punch-Out!!* 的超大角色量身打造，全世界僅此系列使用。 |
| 1988 | **MMC3**：PRG 8KB / CHR 1–2KB 細粒度切換 + **scanline IRQ 計數器** | 固定狀態列、分割捲動、視差、動畫磁磚全部解鎖。NES 後半生的視覺基準線。 |
| 1989 | **VRC6 擴充音源**（2 pulse + 1 saw） | 授權遊戲僅 3 款使用；日版《悪魔城伝説》的音樂高度即由此而來。北美 NES **接腳未接出，完全無法使用**。 |
| 1990 | MMC5：1MB PRG / 1MB CHR + **2 pulse + 8-bit raw PCM** | NES 最強 mapper，但只有 25 片卡帶使用 —— **成本才是真正的限制**。 |
| 1991 | VRC7：**6 聲道 FM 音源** | 僅《Lagrange Point》一款使用。 |
| 1992 | Sunsoft 5B：YM2149F **3 聲道 SSG** | 僅《Gimmick!》一款使用；PAL 版改用無音源的 FME-7。 |
| 1992–93 | 軟體技巧的極限：**Recca** 的 OAM 輪替閃爍、**Kirby's Adventure** 的偽 3D 與視差 | 證明**晚期的軟體技巧比早期的硬體升級更有效**。 |

### mapper 使用統計（授權遊戲，約 2,286 款）[源：NesCartDB]

| Mapper | 款數 | 佔比 |
|---|---|---|
| MMC1 (1) | 671 | 29.4% |
| MMC3 (4) | 579 | 25.3% |
| UxROM (2) | 264 | 11.5% |
| NROM (0) | 242 | 10.6% |
| CNROM (3) | 145 | 6.3% |
| AxROM (7) | 76 | 3.3% |
| MMC5 (5) | 24 | 1.0% |

> **前 5 名合計約佔 83%；MMC1 + MMC3 兩者就佔 ~55%。** 對原創 NES 開發而言，最保險的升級路徑是 **NROM(0) → UxROM(2) → MMC1(1) → MMC3(4)**。需要 scanline 分割畫面 / 狀態列就上 MMC3；需要電池存檔則 MMC1(SNROM) 或 MMC3(TKROM) 都是 8KB 標準配置。[源 / 推論]
