# 02 超級瑪利歐兄弟 3（Super Mario Bros. 3 / スーパーマリオブラザーズ3，1988）

## 摘要（10 行內）
1. 任天堂 EAD 耗時兩年以上打造，公認為 8-bit 平台遊戲設計的集大成之作。[源]
2. 使用 **MMC3（mapper 4）**，PRG 256 KiB + CHR 128 KiB，共 **384 KiB（3 Mbit）**。[源]
3. MMC3 的 **scanline IRQ** 讓狀態列與遊戲畫面分割捲動，並支援**斜向捲動**與**逐幀換 CHR bank 的動畫磁磚**。[源]
4. 引入 **世界地圖（overworld）**，把「線性關卡表」變成「有選擇與存量」的旅程。[源]
5. **P 表（P-Meter）** 把「速度」變成一種可累積的資源，解鎖飛行——速度第一次有了戰略意義。[源]
6. 道具從「狀態」擴張為「套裝」：狸貓、青蛙、鎚子兄弟裝等，等於在同一套關卡上疊多種玩法。[源]
7. 8 個世界、約 90 個關卡；每世界 = 若干關 + 要塞（Boom Boom）+ 飛空艇（庫巴 7 子）。[源]
8. 無電池存檔，但用 **笛子（Warp Whistle）** 與地圖存量道具取代密碼系統。[源]
9. 舞台劇美術語彙（物件被螺絲鎖在背景上、有投影、通關時走向黑幕「下台」）。[源]
10. 全球約 1,700 萬套，NES 史上銷量第三。[源]

## ② 核心迴圈與操作

### 按鍵配置
| 按鍵 | 功能 |
|---|---|
| ←→ | 走 / 跑 |
| ↓ | 蹲；斜坡上蹲 → **滑鏟（Slide）**；空中 ↓ 為狸貓石像 |
| A | 跳；累積 P 表滿時連按 A → **飛行**；浣熊尾巴落下時慢降 |
| B | 加速 / 射火球 / **尾巴橫掃**（浣熊、狸貓） |
| A（地圖） | 進入關卡 / 使用格子道具 |
| Select（地圖） | 開啟道具欄 |
| Start | 暫停 |

### 速度數值（單位：subpixel，16 subpixel = 1 px）[源：TASVideos Game Resources]

| 狀態 | 速度值 | px/frame |
|---|---|---|
| 撞牆彈出 | 16 | 1.000 |
| 飛行中水平速度 | 23 | 1.4375 |
| 走路 / 游泳 | 24 | 1.500 |
| 跑（P 表未滿） | 40 | 2.500 |
| 跑（P 表全滿） | 56 | **3.500** |
| 滑鏟（斜坡） | 63 | 3.9375 |

- 子像素精度：水平位置暫存器 `0x074D` 以 **1/256 px** 為單位累加。[源]
- **下坡跑動額外 +3 subpixel/frame**。[源]
- 牆跳（wall jump，非正規技）需水平速度 ≥ 33 subpixel，且腳部需在 16 px 磚邊界接觸牆面。[源]
- 走路 1.5 px/f 與跑步 2.5 px/f 與前作完全相同 → **系列刻意維持基準手感**，新增的是「P 表全滿 3.5 px/f」這一層。[推論]

### P 表（P-Meter）
- HUD 上為 **7 格箭頭 + 一個 `P` 字**。[源]
- 在地面持續以跑步上限奔跑會逐格填滿；減速、跳起、撞牆會逐格衰減。[源：遊戲行為]
- 全滿後：水平速度提升到 3.5 px/f；若身穿浣熊 / 狸貓裝，連按 A 可進入 **飛行**（飛行期間 P 表持續倒數，歸零即結束）。[源]
- 設計意義：**把「跑得久」轉成「飛得高」的兌換率**，讓長直線跑道第一次有了獎勵。[推論]

### 手感新增
| 動作 | 說明 |
|---|---|
| 浣熊尾巴橫掃 | 近身攻擊，也能打破磚塊、把某些敵人打暈 |
| 慢降（滑翔） | 下落中連按 A，下降速度大幅降低 |
| 狸貓石像 | ↓ + B 變石像，短暫無敵、可壓死下方敵人 |
| 滑鏟 | 斜坡上蹲下，以 3.9375 px/f 衝撞，一次掃掉整排敵人 |
| 踩地（Ground Pound 雛形） | 石像落下即是後續系列「屁股蹲」的原型 [源] |

## ③ 關卡結構

### 三層結構
1. **世界地圖**：節點式路徑圖，有分岔、鎖住的岩石 / 磚塊、蘑菇屋（道具）、黑桃屋（老虎機加命）、白色蘑菇屋（笛子 / P 翼）、敵人遭遇節點（會在地圖上移動的鎚子兄弟）。
2. **一般關卡**：橫向或縱向捲動，1–3 分鐘；有 **斜向捲動**與**多房間（水管 / 門）**。
3. **要塞 + 飛空艇**：世界中段的要塞（打 Boom Boom，破關後永久解鎖路徑）與世界末端的飛空艇（打庫巴的孩子）。

### 8 個世界
| 世界 | 主題 | 魔王 |
|---|---|---|
| 1 Grass Land | 草原（教學） | Larry Koopa |
| 2 Desert Land | 沙漠 / 流沙 / 憤怒太陽 | Morton Koopa Jr. |
| 3 Sea Side | 海洋 / 水中 | Wendy O. Koopa |
| 4 Big Island | 巨大化世界（所有物件 2 倍大） | Iggy Koopa |
| 5 The Sky | 天空（上下兩層地圖） | Roy Koopa |
| 6 Iced Land | 冰原 / 滑地板 | Lemmy Koopa |
| 7 Pipe Maze | 水管迷宮 | Ludwig von Koopa |
| 8 Dark Land | 庫巴領地（坦克 / 軍艦 / 手 / 飛空艇） | 庫巴 |

### 其他結構規則
| 項目 | 內容 |
|---|---|
| 每關長度 | 典型 60–120 秒（計時 300 或 400） |
| 捲動 | 水平、垂直、**斜向**；部分關卡強制自動捲動 |
| 檢查點 | **無關內檢查點**；死亡回到該關起點（但保留地圖進度） |
| 存檔 | 無；以笛子（跳世界）+ 命數管理取代 |
| 分支 | 地圖上多路徑、隱藏道路（用笛子 / 雲朵跳過）、關卡內多水管出口 |
| 祕密 | 白色蘑菇屋（尾巴掃出）、笛子（1-3 後方隱藏區、要塞 1 天花板、2 沙漠白屋）、N-Spade 老虎機 |

## ⑤ 魔王設計

### Boom Boom（每世界要塞，共 8 次）
| 階段 | 行為 |
|---|---|
| 基本 | 左右衝刺、揮舞雙手；踩 3 次擊敗 |
| 變體 A | 跳躍型（後期世界） |
| 變體 B | 長出翅膀飛行型（後期世界） |
- 設計意義：**同一個魔王重複 8 次，但每次換 1 個行為參數**，用最低成本提供「熟悉 + 意外」。[推論]

### 庫巴 7 子（飛空艇）
| 魔王 | 招式 | 弱點 / 階段 |
|---|---|---|
| Larry | 魔杖射彈 + 小跳 | 踩 3 次；地板有**下陷磚** |
| Morton | 重踩造成**畫面震動使玩家僵直** | 踩 3 次；需在震動空檔攻擊 |
| Wendy | 發射**會彈跳的戒指環**（沿牆反彈） | 踩 3 次；地板為斜坡 |
| Iggy | 跳躍 + 射彈，地板為**可傾斜的蹺蹺板** | 踩 3 次；掉落即死 |
| Roy | 重踩震動（同 Morton）+ **牆面向內壓縮** | 踩 3 次；活動空間遞減 |
| Lemmy | 乘球滾動、**丟出滿地彈跳球** | 踩 3 次；需清出落腳點 |
| Ludwig | 射彈頻率最高 + 重踩震動 + 跳得最高 | 踩 3 次；綜合版 |

- 全部 7 個共用「射彈 + 縮殼衝刺 + 踩 3 次」核心；差異放在 **場地機關** 與 **一種附加效果**。[推論]

### 庫巴（8-庫巴城）
| 階段 | 招式 | 破法 |
|---|---|---|
| 1 | 跳躍震地、吐火 | 躲在磚縫 |
| 2 | 連續高跳，落點**踩破地板磚** | **誘導他自己把地板砸穿**，跌落即敗 |
- 首次出現「**不打，而是誘使魔王自毀**」的解法，也可用火球硬打。[源]

### 地圖道具（存量制）
蘑菇 / 火之花 / 樹葉 / 各套裝 / 星星 / **音樂盒（讓地圖敵人睡著）** / **鎚子（砸開地圖上的岩石）** / **雲朵（跳過一關）** / **錨（保留飛空艇位置）** / **笛子（跳世界）**。

> 這是本作最大的系統創新：道具不再只是「撿到就用」，而是**可儲存、可規劃的戰略資源**（最多 28 格）。[源]

- 連續踩敵表與前作類似，終點為 1-UP。
- 關末的終點卡片（蘑菇 / 花 / 星），集滿三張同圖案給額外命（星星 ×3 = 5 命）。[源]

## ⑦ 難度曲線與教學手法

1. **1-1 重新教一次基本操作，但假設玩家已會**：關卡一開始就給超級樹葉，先讓玩家「感受新能力」再談挑戰。[推論]
2. **世界即主題課**：每個世界以一個機制為主軸（2 = 流沙與太陽、4 = 尺寸感、5 = 高低兩層地圖、6 = 摩擦力、7 = 拓撲）。這是「一個世界教一件事」的教科書式編排。[推論]
3. **地圖讓玩家自選難度**：可繞過部分關卡、可先打蘑菇屋補道具，**難度由玩家調節**而非設計者單向規定。[推論]
4. **失敗成本分層**：關內死亡只損失一條命 + 該關道具；整個世界進度保留在地圖上 → 鼓勵嘗試高風險路線。[推論]
5. **起承轉合（Kishōtenketsu）**：典型關卡先在安全處展示新機關（起）、加量（承）、與舊機關組合產生變化（轉）、最後一次高強度應用（合）。任天堂在《超級瑪利歐 3D 世界》由林田宏一正式說明此方法論。[源]
6. **飛空艇 = 世界期末考**：自動捲動 + 密集陷阱 + 魔王，強制檢驗該世界所學。[推論]
7. **8-1 之後的 Dark Land** 取消了「按順序」的假設，改成軍艦 / 坦克 / 手掌等特殊關卡，用「陌生感」取代「數值難度」。[推論]

## ⑧ 技術亮點

1. **MMC3 scanline IRQ 分割畫面**：在特定掃描線觸發 IRQ、改寫捲動暫存器，使畫面上方（狀態列）固定、下方自由捲動。地圖畫面時同一機制改用來顯示道具欄。[源]
2. **斜向（雙軸）捲動**：MMC3 提供 bank 切換與 IRQ，配合 4 畫面 / 鏡像設定，做到 8-bit 少見的平順斜向捲動。[源]
3. **動畫磁磚**：以**逐幀切換 CHR bank** 的方式讓背景（水波、問號磚、火焰）動起來，而不消耗 sprite。[源]
4. **舞台劇式美術**：所有平台都畫上螺絲、鋼索與投影，**把「這是拼貼上去的磁磚」這個硬體限制改寫成藝術設定**。[源＋推論]
5. **384 KiB 容量分工**：128 KiB 全給 CHR，讓 8 個世界各有獨立圖塊組。[源]
6. **P 表與飛行**只需一個計數器與一組速度上限，**幾乎零額外資料成本就換來一整套新玩法**。[推論]

## ⑨ 音樂音效特色

- 作曲：近藤浩治。他自述這是「最難寫的一次」，因為必須超越初代。[源]
- 每個世界有專屬主題曲（草原、沙漠、海、巨大、天空、冰、水管、暗黑），加上要塞、飛空艇、魔王、蘑菇屋、P 開關、老虎機等情境曲，總曲目遠多於初代。[源]
- **P 開關曲**是單獨一段短促循環，與「限時倒數」的緊迫感綁定 → 音樂本身成為 UI。[推論]
- P 表填滿時的「衝刺音」與電影配樂中的上行音階同構，後來在《超級瑪利歐兄弟大電影》中被直接引用。[源]
- 使用 DPCM 取樣播放鼓聲，比初代的純噪音聲道厚實。[推論]

## ⑩ 對原創遊戲的可借鑑清單（10 條）

1. **保留前作的基準速度（1.5 / 2.5 px/f），只在上面疊一層（3.5 px/f）**：續作不要改手感，要「加層」。
2. **把速度做成可累積的資源條**：7 格的 P 表，滿了才解鎖特殊動作；跳起 / 減速逐格衰減，玩家必須主動維持。
3. **世界地圖 + 道具存量（上限 28 格）**：讓玩家在關卡外做決策，難度由玩家自行調節。
4. **一個世界只教一件事**：草原（基礎）→ 沙漠（常駐壓力）→ 巨大化（尺寸感）→ 冰（摩擦力）→ 水管（拓撲）。
5. **同一個中魔王重複 N 次、每次只改 1 個參數**（走 → 跳 → 飛），用最低成本製造熟悉與意外。
6. **主要魔王共用核心循環，差異放在場地**：斜坡、蹺蹺板、壓縮牆、下陷磚——換場地比換 AI 便宜十倍。
7. **提供「非戰鬥解法」**：最終魔王可用「誘導他砸穿自己腳下的地板」擊敗，給不擅長戰鬥的玩家一條路。
8. **裝備型能力（套裝）而非單一升級線**：浣熊（機動）/ 青蛙（水下）/ 鎚子（防禦 + 攻擊），同一關卡因裝備不同而有不同最佳解。
9. **敵人可被奪取的裝備**（庫力伯靴）：讓玩家對敵人產生「想要」而非只是「想殺」。
10. **技術限制當設定**：背景是「舞台佈景」，所以物件有螺絲、有投影、通關走向黑幕——把 tile 拼貼感正當化。
