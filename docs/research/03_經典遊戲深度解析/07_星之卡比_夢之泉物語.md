# 07 星之卡比 夢之泉物語（Kirby's Adventure / 星のカービィ 夢の泉の物語，1993）

## 摘要（10 行內）
1. HAL 研究所開發、任天堂發行，1993-03-23 於 Famicom 推出；是 NES 生命週期末期的技術展示作。[源]
2. **6 Mbit（768 KiB）**，是 NES 最大的遊戲之一，但刻意**不用最強的 MMC5、改用便宜的 MMC3**。[源]
3. Mapper MMC3：**PRG 512 KiB（32 × 16 KiB）+ CHR 256 KiB（32 × 8 KiB）**，且**內建 SRAM 電池存檔**（3 個檔案）。[源]
4. 監督櫻井政博。系列首次導入 **複製能力（Copy Ability）**，共 **25 種**（含最終戰的星之杖）。[源]
5. 開發初期做了 **40 種以上**能力，最後由團隊投票篩選。[源]
6. **7 個世界、41 個關卡**＋最終的「夢之泉」；每個世界有大廳式地圖、隱藏開關、小遊戲、博物館與競技場。[源]
7. 卡比可**無限飛行**——這是史上第一次有平台遊戲把「跳躍失誤」這個失敗來源基本移除。[源]
8. 難度靠「**可選的深度**」而非「懲罰」：主線寬鬆，100% 完成度（找齊所有隱藏開關）才是真正的挑戰。[源]
9. 破關後解鎖 **Extra Mode（生命上限降為 3 格）**，是內建的第二輪難度。[源]
10. 音樂由安藤浩和與石川淳擔任；IGN 稱其為 NES 視覺與聽覺的最高技術成就之一。[源]

## ② 核心迴圈與操作

### 按鍵配置
| 按鍵 | 功能 |
|---|---|
| ←→ | 走；連按 → 跑 |
| ↓ | 蹲；↓ + A = **滑鏟（Slide）** |
| A | 跳；**空中再按 A = 吸氣鼓起並飛行（可無限重複）** |
| B | **吸入（Inhale）**；含著敵人時 B = 吐出星星 |
| ↓（含著敵人時） | **吞下 → 取得複製能力** |
| B（有能力時） | 發動該能力 |
| Select | **主動丟棄目前能力**（能力會變成可再吸的星星） |
| A（飛行中）/ B | 吐出空氣彈（弱攻擊，且會解除飛行） |
| Start | 暫停；暫停畫面可查看目前能力的說明 |

### 手感規則（與同期作品的根本差異）
1. **無限飛行**：卡比可以隨時鼓起身體飛行，沒有時間或次數限制。掉落死亡幾乎只發生在「畫面外的無底洞」。[源]
2. **飛行的代價**：飛行中只能吐出弱小的空氣彈，且吐出後**立刻解除飛行**。所以飛行 = 安全但無輸出。這是全作最精巧的平衡設計。[推論]
3. **含著敵人時不能飛、不能再吸**：吸入與飛行共用「嘴巴」這個資源，所以玩家必須在「拿著彈藥」與「機動性」間二選一。[源]
4. **能力在受傷時掉落**：被打中會噴出一顆彈跳的能力星，數秒內可吸回。這讓受傷的懲罰是「暫時失去工具」而非「扣命」。[源]
5. **水中**：不能吸入與一般攻擊，只能噴短射程水柱；部分能力仍可使用。[源]
6. **同時吸入兩個有能力的敵人並吞下 → 觸發能力輪盤**（隨機抽所有能力，按 A 定住）。[源]

### 生命
| 項目 | 內容 |
|---|---|
| 初始命數 | 4 |
| 生命條 | **6 格**（Extra Mode 為 3 格） |
| 受傷 | 扣 1 格 + 掉落能力 |
| 即死 | 掉出畫面下緣 |
| 死亡後 | 從該關**最後到達的區域**重新開始（不是整關） |
| Game Over | 可選 CONTINUE（回到最後到達的關卡）或 GAME END |

### 核心迴圈
`吸入敵人 → 決定「吐出當子彈」或「吞下拿能力」 → 用能力開路 / 打怪 → 受傷失去能力 → 重新取得或改拿別的`

這是一個**低風險、高頻率的實驗迴圈**：櫻井政博明言複製能力的目的是「讓玩家實驗、提高重玩價值」，以回應前作《夢之泉》太過簡單的批評。[源]

## ③ 關卡結構

### 三層結構
1. **世界地圖（Lobby）**：不是路徑圖，而是**一個可自由走動的大廳畫面**，門即關卡。門的種類：
   | 門 | 功能 |
   |---|---|
   | 數字門 | 一般關卡；完成後數字變暗並插旗 |
   | **白門 / 棕門** | **完成後若仍是棕色 = 該關還有未按的隱藏開關** |
   | 魔王門 | 全關完成後出現 |
   | 返回門 | 回上一個世界 |
   | **博物館 Museum** | 裡面放著 1–2 隻「無害展示中」的敵人，可自由吸取能力 |
   | **競技場 Arena** | 與一隻中魔王對戰，勝利給 Maxim 番茄，並可取得其能力 |
   | Warp Star Station | 世界間快速移動 |
   | 小遊戲（Crane Fever / Egg Catcher / Quick Draw） | 玩一次後永久關閉 |
2. **關卡（Stage）**：由數個「區域（Area）」以門串接；每關 3–6 個區域。
3. **關末彈跳台**：通關後站上彈簧，抓準時機按鈕跳得越高分數越高；**完美跳躍給 1-UP**。[源]

### 7 個世界 + 終章
| # | 世界 | 主題 | 魔王 |
|---|---|---|---|
| 1 | Vegetable Valley 蔬菜谷 | 草原（教學） | **Whispy Woods** |
| 2 | Ice Cream Island 冰淇淋島 | 沙漠 / 海島 | **Paint Roller** |
| 3 | Butter Building 奶油大廈 | **繞塔而上**的垂直世界 | **Mr. Shine & Mr. Bright** |
| 4 | Grape Garden 葡萄園 | 空中 / 氣流 | **Kracko** |
| 5 | Yogurt Yard 優格庭院 | 瀑布 / 洞窟 | **Heavy Mole** |
| 6 | Orange Ocean 橘子海洋 | 海岸 / 水中 | **Meta Knight** |
| 7 | Rainbow Resort 彩虹渡假村 | 冰雪 / 星空 / **中魔王連戰塔** | **King Dedede** |
| 終 | The Fountain of Dreams 夢之泉 | 最終戰（使用星之杖） | **Nightmare Orb → Nightmare Vampire** |

### 分支與祕密
- **隱藏開關（Hidden Switch）**：每個世界散佈數個；按下後會在世界地圖上開啟新的門（小遊戲、競技場、Warp Star）。**全部找齊才能達成 100%**。[源]
- 破關後顯示完成度百分比；100% 解鎖 **Extra Mode（生命上限 3 格）** 與小遊戲重玩。[源]
- 關卡內大量「需要特定能力才能取得」的 1-UP 與 Maxim 番茄（例如用 Hammer 打樁、用 Laser 斜反射打牆、用 Crash 點燃引信）。[源]

## ④ 敵人設計（代表 10 種）

| # | 敵人 | 行為模式 | 可得能力 | 教學意義 |
|---|---|---|---|---|
| 1 | **Waddle Dee** | 只會走路，部分會跳 | 無 | 全作的「彈藥」與教學對象：第一次吸入就是牠 |
| 2 | **Waddle Doo** | 走路 + 短射程光束鞭 | **Beam** | 本作第一個複製能力；教「敵人的招式就是你的招式」 |
| 3 | Bronto Burt | 靜止，接近後朝玩家飛來 | 無 | 教「空中威脅」與飛行中的閃避 |
| 4 | **Cappy** | 第一次吸只會吸走牠的帽子；帽子可當子彈射 | 無 | 教「吸入有層次」：有些東西要分兩步 |
| 5 | **Kabu** | 定時消失 / 在別處出現；閃爍中無敵 | 無 | 教「無敵相位」與等待 |
| 6 | **Scarfy** | 外表可愛；**吸不進去**，被吸就翻臉追擊並自爆 | 無 | 全作最重要的一課：**可愛≠安全**，並教「別什麼都吸」 |
| 7 | **Gordo**（刺球） | 水平或垂直來回移動；**完全不可破壞** | 無 | 教「有些障礙只能閃」——用能力（Fireball / Wheel）快速通過 |
| 8 | **Shotzo**（砲台） | 不可破壞，定時朝玩家方向射擊 | 無 | 教「固定砲台的射線管理」 |
| 9 | **Sir Kibble** | 定點投擲長射程迴力刃 | **Cutter** | 教「遠程能力」；Cutter 是全作最泛用的開路工具 |
| 10 | **Bomber** | 接近後爆炸，範圍大 | **Crash**（全螢幕清場，只能用一次） | 教「一次性的大招資源」與風險報酬 |

> 其他代表性能力敵：Sparky（Spark）、Laser Ball（Laser）、Hot Head（Fire）、Flamer（Fireball）、Chilly（Freeze）、Pengy（Ice）、Parasol（Parasol）。[源]

## ⑤ 魔王設計

| 魔王 | 招式 | 弱點 / 破法 | 階段 |
|---|---|---|---|
| **Whispy Woods**（W1） | 吐出蘋果（可吸）、噴出空氣彈、根部凸起 | 把蘋果吸進來吐回去；任何能力皆可 | 單階段；**經典的「教學魔王」** |
| **Paint Roller**（W2） | 在畫布上**畫出物件並讓它衝出來**（球、炸彈、UFO 等），畫什麼就出現什麼 | 吸入牠畫出來的東西反擊（棒球→Ball、炸彈→Crash） | 單階段；**魔王本身就是能力供應器** |
| **Mr. Shine & Mr. Bright**（W3） | 太陽與月亮**交替登場**：一個投擲火焰、一個投擲新月刃 | 兩者交替時的空檔；需分辨當下面對的是誰 | 雙體交替 |
| **Kracko**（W4） | 雲中之眼：放電、俯衝、召喚 Waddle Doo | 先打掉小雲（Kracko Jr.）階段，再打本體 | **2 階段**（Jr. → 本體） |
| **Heavy Mole**（W5） | **強制捲動追逐戰**：鑽地機在後方緊追，玩家邊逃邊打 | 邊往前跑邊回頭攻擊 | 單階段但為「橫向捲動 + 時間壓力」 |
| **Meta Knight**（W6） | **丟一把劍給卡比**，然後正面劍鬥；衝刺斬、龍捲斬 | 只能用劍（Sword）對決 | 單階段；**唯一一場「公平決鬥」** |
| **King Dedede**（W7） | 大槌揮擊、跳躍震地、**吸入卡比**、空中滑翔衝撞 | 吸入被震落的星星反擊 | 單階段；系列傳統最終王 |
| **Nightmare Orb**（終） | 空戰：發射大量暗星、衝撞、能量波；**有時間限制（雲層逐漸變白＝即將墜落）** | 使用**星之杖**射星 | 最終第 1 形態 |
| **Nightmare Vampire**（終） | 巨大人形：瞬移、暗影彈 | 星之杖 | 最終第 2 形態；連戰無補給 |

### 設計觀察
- **魔王幾乎都提供「彈藥」**：蘋果、畫出來的物件、被震落的星星——魔王自己供給玩家反擊手段，所以即使空手也打得贏。[推論]
- **Meta Knight 丟劍給你** 是本作最著名的設計：它把「公平」寫進了機制，而不只是劇情。[源]
- 難度由「機制新奇度」而非「HP 與傷害」承擔：Heavy Mole 是追逐、Paint Roller 是隨機供應、Mr. Shine & Bright 是雙體交替。[推論]

### 成長模型
- **沒有永久成長**。所有能力都是暫時的、可丟棄的、可替換的。
- 玩家的「成長」是 **對能力庫的認識**：知道哪個能力能開哪扇門。這正是 100% 完成度的核心。[推論]

## ⑦ 難度曲線與教學手法

1. **1-1 完全不會死**：平坦地形、只有 Waddle Dee，讓玩家先發現「吸入 → 吐出」；下一段才給 Waddle Doo（第一個能力）。[源]
2. **無限飛行＝取消「跳躍失誤」這個失敗來源**：櫻井政博的目標是讓新手與兒童也能玩完。難度被移到「探索與收集」，而不是「通過」。[源＋推論]
3. **博物館 = 能力試用店**：在安全的房間裡放一隻無害的能力敵，玩家可以反覆試、隨時換。這是把「教學」做成一個可重複造訪的地點。[源]
4. **能力輪盤與 Select 丟棄**：兩個設計都在降低「選錯能力」的成本，鼓勵實驗。[源]
5. **隱藏開關 = 可選的硬核層**：主線可以無腦推完，但棕色的門會一直提醒玩家「這關還沒挖乾淨」。**用視覺狀態而非文字做進度提示。**[源]
6. **中魔王競技場**：玩家可以回頭刷取任何能力，把「我需要 Hammer」變成可執行的計畫。[源]
7. **Extra Mode**：破關 100% 後把生命上限降為 3 格，是最便宜的第二輪難度（不改任何關卡）。[源]
8. **關末彈跳台**：一個 1 秒的時機小遊戲，完美就給 1-UP。它讓每一關結束都有一個「再一次」的微型挑戰。[源]

## ⑧ 技術亮點

1. **6 Mbit 卻用 MMC3 而非 MMC5**：MMC3 更便宜、更常見；HAL 用軟體技巧補足硬體差距，是成本工程的典範。[源]
2. **雙倍寬度的遊戲區 + 固定狀態列**：把可視範圍加倍並環繞（wrap），使畫面捲動時**永遠不會捲到狀態列**，配合 MMC3 的 scanline IRQ 做出穩定的分割畫面。[源：NESdev 討論]
3. **奶油大廈的「繞塔」演出**：以背景重繪 + 捲動偽造「繞著圓塔走」的 3D 感，是 NES 上罕見的空間錯覺。[推論]
4. **精靈多工（sprite multiplexing）**：卡比在不同能力下有完全不同的動畫組，靠 CHR bank 的即時切換（256 KiB CHR）而非把所有幀都放在同一個 bank。[源＋推論]
5. **明顯的減速（slowdown）作為設計取捨**：HAL 選擇讓畫面掉幀而非閃爍或刪除物件，確保「玩家看到的等於實際存在的」。[推論]
6. **SRAM 自動存檔**：每完成一關自動寫入，3 個檔案並記錄完成度百分比——在 1993 年的動作遊戲中相當前衛。[源]
7. **調色盤管理**：大量使用漸層天空與柔和色，透過每個 world 的專屬 palette 組合做出「粉彩」風格，脫離 NES 典型的高對比配色。[源]

## ⑨ 音樂音效特色

- 作曲：安藤浩和、石川淳。[源]
- 風格與同期 NES 作品相反：**大調、明亮、大量三度與六度和聲**，速度中等，強調「可愛」而非「緊張」。[推論]
- 代表曲：Vegetable Valley（主題）、Butter Building（被系列反覆重編最多次的一首）、Yogurt Yard、Rainbow Resort、Fountain of Dreams（Meta Knight 主題的前身）。
- 三角波不只作貝斯，也常做**對旋律（counter-melody）**，讓編曲聽起來比兩支脈衝波更厚。[推論]
- 大量使用 DPCM 取樣鼓組與短音效（吸入、吞下、變身），使動作回饋極為明確。[推論]
- **每個複製能力都有專屬音效**，玩家用聽的就知道自己現在是什麼形態。[推論]

## ⑩ 對原創遊戲的可借鑑清單（10 條）

1. **把「失敗來源」直接移除一項**（如無限飛行取消墜落死亡），然後把難度搬到收集與探索上。適合面向廣泛年齡層的遊戲。
2. **給自由，但讓自由有代價**：卡比能無限飛，但飛行中只能吐出弱攻擊且吐完立刻落地。一條規則就平衡了一個看似破壞平衡的能力。
3. **共用資源製造抉擇**：「嘴巴」同時是彈藥槽與飛行器官，含著東西就不能飛也不能再吸。用同一個資源承擔兩種功能，天然產生取捨。
4. **能力 = 敵人的招式**：每種可複製的敵人只給一種能力，玩家看到敵人就知道能拿到什麼，不需要說明書。
5. **受傷的懲罰是掉能力而非扣命**，且能力會彈跳數秒可撿回 —— 給玩家一個「補救的窗口」。
6. **設一個「博物館」**：安全房間裡放無害的能力敵，讓玩家隨時試用與更換。教學變成一個可重複造訪的地點。
7. **中魔王 = 能力販賣機**，並允許在地圖上的競技場重複挑戰，把「我想要某個能力」變成可執行的計畫。
8. **用門的顏色顯示隱藏內容是否已找齊**（白＝完成、棕＝還有開關）。以視覺狀態取代文字提示做進度管理。
9. **魔王自己供應彈藥**（蘋果、畫出來的物件、震落的星星），確保空手玩家也有勝算。
10. **破關後只改一個數字就做出第二輪**（生命上限 6 → 3），零額外關卡成本；再加上關末彈跳台這種 1 秒的時機小遊戲，每關結束都有一次「再來一下」。
