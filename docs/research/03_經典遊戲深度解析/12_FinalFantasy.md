# 12 Final Fantasy（1987）深度解析

## 摘要（10 行內）
1. 1987-12-18 於日本 Famicom 發售，北美 NES 版 1990-07；開發／發行皆為 Square。[源]
2. 坂口博信企劃・監督，植松伸夫音樂，天野喜孝角色設計，Nasir Gebelli 主程式。[源]
3. ROM：**MMC1、PRG 256 KB、CHR-RAM、電池備份 SRAM**。[源]
4. 玩家自選 4 人隊伍、6 種職業，中期經由巴哈姆特 + 鼠尾（Rat Tail）**職業昇級**。[源]
5. 魔法採 **D&D 式「法術等級 × 使用次數」制**：8 個等級、每級可學 3 個、每級最多 9 次。[源]
6. 戰鬥採**橫向視角**：角色在右、敵人在左，是日式 RPG 視覺語言的分水嶺。[推論]
7. 傷害 = rand(基礎, 基礎×2) − 敵防；命中 = rand(0,200) < 168 + 命中率 − 迴避。[源]
8. NES 版有多個著名 bug：**智力（INT）完全無效**、**爆擊率誤用武器索引值**、屬性／種族特攻不生效。[源]
9. 銷量：Famicom 52 萬、NES 70 萬，1994 年前合計約 130 萬套。[源]
10. 終局為「時間迴圈」結構：回到 2000 年前的混沌神殿打倒 Chaos，故事首尾相扣。[源]

## ② 核心迴圈與操作

**巨觀迴圈**：世界地圖移動（隨機遇敵）→ 城鎮補給／買魔法 → 迷宮探索（固定寶箱 + 遇敵）→ 四天王之一 → 取回水晶 → 新交通工具 → 世界擴張。

**戰鬥迴圈**
- 回合開始時**一次輸入全隊 4 人指令**，然後整個回合演算完畢（不能中途改）。
- 因此產生了本作最有名的缺陷體驗：**指定的敵人若在你出手前已死亡，該次攻擊會空揮（"Ineffective"）**——這直接教育了整整一代玩家「要分散目標」。[推論]
- 指令：FIGHT / MAGIC / DRINK / ITEM / RUN。
- 魔法用「次數」而非 MP，**次數用完就沒了**，所以旅途中的資源管理（何時用回復、何時用道具）才是真正的難度。[源/推論]

## ③ 世界／關卡結構

**推進順序（軟性線性）**[源]
1. Cornelia（起點）→ 打倒 Garland → 取回公主 → 得到 Lute
2. Pravoca（得船）→ Elfheim → Marsh Cave（王冠）→ Western Keep（Astos／水晶之眼）→ Matoya（藥草）
3. Mt. Duergar 矮人（火藥）→ 炸開運河 → Melmond → 土之洞窟（**Lich**）
4. Crescent Lake → Mt. Gulg（**Marilith**）→ Ice Cavern（Levistone）→ **飛空艇**
5. Citadel of Trials（鼠尾）→ 巴哈姆特**職業昇級**
6. 海底神殿（**Kraken**）→ Rosetta Stone → Lufenia → 浮遊城（**Tiamat**）
7. 混沌神殿 → 回到 2000 年前 → 四天王重戰 → **Chaos**

**結構觀察**
- 表面線性，但「鑰匙道具 + 交通工具」的鎖鏈很長：船 → 運河 → 飛空艇 → 潛水 → 傳送方塊，每一段都把可達範圍擴大一圈。[推論]
- 迷宮是多層樓、以固定寶箱與 MP（次數）消耗為壓力源；沒有迷宮地圖，但層級結構比 Zelda 單純。[推論]
- 迷路對策主要靠 NPC 提示與「船能停的海岸只有幾處」這種地形限制。[推論]
- **時間迴圈終局**：Garland 被送回 2000 年前成為 Chaos，Chaos 又把 Garland 送回未來——打倒後這段時間被抹除，是 8-bit 時代罕見的敘事技巧。[源]

## ④ 系統數值與公式

### 命中與傷害 [源]
```
攻擊力（有武器）  = 武器攻擊力 + 力量 ÷ 2
攻擊力（空手黑帶）= 等級 × 2
單次傷害 = rand(攻擊力, 攻擊力 × 2) − 敵方 Absorb（防禦），最低 1
命中判定 = rand(0, 200) < (168 + 角色命中率) − 敵方迴避
攻擊次數 由命中率決定（黑帶／忍者的次數成長加倍）
```

### 魔法 [源]
- 8 個法術等級，每級可學 **3 個**（白 3 + 黑 3 分開，紅魔可兩邊學但不能學全部）。
- 每個等級有獨立的**使用次數**，白／黑魔導士約 Lv50 時各級達上限 **9 次**；騎士／忍者昇級後才開始獲得次數，上限 **4 次**。
- **魔法傷害不隨等級成長**（因為 INT 無效），所以後期黑魔法迅速失去價值——這是本作平衡最大的裂縫。[源]

### 著名 bug [源]
| Bug | 影響 |
|---|---|
| **智力（INT）無效** | 魔法威力永遠固定，法師後期疲軟 |
| **爆擊率誤讀武器索引** | 前期爆擊偏少、後期（高索引武器）爆擊過多 |
| 屬性／種族特攻無效 | 許多「對某族加成」武器實際沒作用 |
| 狀態命中判定錯誤 | 部分減益／抗性不如說明 |
| Peninsula of Power | 特定地形格上出現遠高於該區的敵人（可高速練級） |

**設計啟示**：一款有這麼多數值 bug 的遊戲仍成為經典，說明**節奏、世界感與職業幻想**比數值正確性更能撐起 RPG。[推論]

## ⑤ 敵人設計

- 敵人以「群」為單位配置（最多 9 隻小型或 4 隻大型），玩家的群體法術價值隨編組浮動。[推論]
- 分工明確：物理牆（Iron Golem 類）、法術炮台（Wizard 類）、狀態異常（Cockatrice 石化、Ghoul 麻痺）、消耗戰（高迴避的 Ninja 類）。[推論]
- **狀態異常（石化／死亡／麻痺）才是真正致命的東西**，逼玩家常備解除道具與白魔法。[推論]
- **WarMECH**（浮遊城的稀有遇敵）：極低出現率 + 極高威脅，是「傳說級遭遇」的原型設計，靠玩家口耳相傳產生神話。[推論／常見資料]
- 迷宮固定寶箱旁常配強敵，形成「貪不貪」的小決策。[推論]

## ⑥ 魔王／高潮設計

| 魔王 | 位置 | 機制重點 |
|---|---|---|
| Garland | 序章 | 教學型魔王，展示「指令戰鬥」的基本節奏 |
| Astos | Western Keep | 高階魔法（DETH 即死），教玩家怕魔法 |
| Lich（土） | 土之洞窟 | 群體攻擊，考回復輪替 |
| Marilith（火） | Mt. Gulg | 多段物理，考防禦與 buff |
| Kraken（水） | 海底神殿 | 高攻擊力，考裝備更新 |
| Tiamat（風） | 浮遊城 | 全屬性魔法，考抗性裝 |
| 四天王重戰 | 混沌神殿 | 資源耗盡戰：四場連續、沒有補給點 |
| **Chaos** | 終點 | Garland 的最終型態；全體大魔法 + 回復自己，是純粹的耐力與資源考試 |

**高潮設計**：最終迷宮把「四天王全部重打一次」變成一條沒有存檔點的長廊——**難度來自資源管理而非單場強度**，這是「次數制魔法」系統的必然歸宿。[推論]

## ⑦ 職業／裝備／成長

### 六職業與昇級 [源]

| 初始職業 | 昇級後 | 特色 |
|---|---|---|
| Fighter 戰士 | Knight 騎士 | 最高防禦；昇級後可用初級白魔法 |
| Thief 盜賊 | Ninja 忍者 | 逃跑率高；昇級後可用初級黑魔法、前期弱後期強 |
| Black Belt 黑帶 | Master 武術家 | **空手傷害 = 等級 × 2**，不用買武器 = 省錢流 |
| Red Mage 紅魔 | Red Wizard 紅魔導 | 萬能但每級法術學習受限 |
| White Mage 白魔 | White Wizard 白魔導 | 回復與輔助核心 |
| Black Mage 黑魔 | Black Wizard 黑魔導 | 前中期火力核心，後期受 INT bug 拖累 |

- **昇級條件**：取得 Citadel of Trials 的鼠尾，交給龍王巴哈姆特 → **全隊一次昇級**。[源]
- 昇級是純粹的上位替換（更好的裝備權限 + 新法術），沒有 DQ3 那種「重練代價」。兩種設計哲學的對照很值得研究：**DQ3 的轉職是取捨，FF1 的昇級是獎勵**。[推論]

### 裝備與經濟
- 裝備是主要戰力來源（因為每級只 +1 點屬性），所以「錢 → 裝備」的迴圈遠比練級重要。[源/推論]
- 職業決定可裝備清單，形成「買給誰」的隊伍層級決策。[推論]

## ⑧ 難度曲線與教學

- **開局最痛**：Lv1–3 隊伍極脆，一次遇敵就可能全滅；當年這被視為「RPG 的門檻」，現代標準則需要調整。[推論]
- 教學靠說明書與 NPC；遊戲內幾乎沒有教學段落（時代限制）。[推論]
- 難度靠三個閥門調節：練級、買裝備、法術次數管理——**全部由玩家自選**。[推論]
- 死亡懲罰：全滅回上次存檔（電池存檔可在世界地圖隨時進行），實質懲罰是時間。[推論]
- 四天王之間的難度階梯明顯（Lich → Marilith 需要重新整備），每次都伴隨新城鎮與新裝備。[推論]

## ⑨ 技術亮點

1. **橫向視角戰鬥畫面**：角色與敵人同框、隊伍在右側排列，是 JRPG 視覺語言的起點（DQ 系列則是第一人稱）。[推論]
2. **Nasir Gebelli 的程式**：在 256 KB 內塞進世界地圖、數十個場景、200+ 敵人與八級魔法表。[源/推論]
3. **CHR-RAM + MMC1**：圖塊集可依場景整批切換（世界地圖／城鎮／戰鬥／迷宮各一套）。[源/推論]
4. **交通工具改變地圖演算**：船、運河、飛空艇、潛水各自改寫可通行判定，用同一張地圖做出四種世界。[推論]
5. **資料驅動的職業／法術表**：職業昇級只是換一張表，成本極低但體感巨大。[推論]

## ⑩ 音樂音效特色

- 植松伸夫在此確立系列音樂語彙：**Prelude（豎琴式琶音）**、Opening Theme（プロローグ）、勝利 fanfare、戰鬥曲。[推論／系列常識]
- Prelude 僅用上下行琶音（兩個聲道即可）就撐起「史詩感」——是 2A03 上「以最少音符換最大氛圍」的示範。[推論]
- 勝利 fanfare + 戰鬥曲的組合，把回合制戰鬥的情緒起伏標準化：緊張 → 解決 → 獎勵。[推論]
- 城鎮曲／迷宮曲的對比鮮明；Matoya 洞窟等曲子帶有詼諧色彩，讓世界不只有壓迫感。[推論]

## ⑪ 對原創遊戲的可借鑑清單（10 條）

1. **次數制魔法（法術等級 × 使用次數）**：比 MP 制更容易產生「跨場景資源管理」，而且數值極小（0–9），適合像素／掌機 UI。
2. **開局選隊伍 = 選遊戲難度與風格**：4 人 × 6 職 的組合本身就是重玩理由。
3. **職業昇級當作中期大獎**：一次性全隊升格，換美術（換色／換圖）成本低、體感極強。
4. **空手職業（黑帶）**：讓「不買武器」成為一種可行 build，等於在經濟系統裡開一條旁路。
5. **交通工具改寫通行判定**：同一張地圖用「船／飛行／潛水」拆成四個階段，是小地圖擴充內容的最佳手段。
6. **回合一次輸入全隊指令**：介面單純、適合手把；但要修掉「目標已死就空揮」的挫折（現代作法：自動改打下一個目標）。
7. **最終迷宮 = 資源耗盡戰**：把之前的魔王重排成一條無補給長廊，難度來自續航而非單場強度。
8. **敘事收束技巧**：時間迴圈／首尾相接的結局，成本只有幾段文字，卻能讓短篇作品有「完整感」。
9. **裝備優先於等級**：每級只給少量屬性、把戰力放在裝備上，可讓玩家用金錢而非時間解決卡關。
10. **教訓：數值系統要能驗證**。INT 無效與爆擊率讀錯索引這種 bug 在當年無法被玩家證實；今天應該寫**戰鬥模擬腳本**自動跑一萬次驗證期望值。
