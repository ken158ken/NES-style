## 1. 基礎操控細節

### 1.1 走 / 跑（Dash）
| 項目 | 原作行為 | 來源 | 本作現況 / 建議 |
|---|---|---|---|
| 走路 | 按住方向鍵即走 | [源] Wikibooks KSS Basic Controls | 已有，走 1.3 px/f |
| 跑步觸發 | **連點兩下同方向、第二下按住**（double-tap and hold）。不是「按久了自動加速」 | [源] Wikibooks：「double-tap the D-Pad, holding on the second tap」 | 已有（engine_test 有 `double-tap run` PASS）。建議雙擊判定窗 **12~14 幀** [本作] |
| 跑步中止 | 放開方向鍵或轉身即回走路；轉身有煞車動作 | [慣例] | player-feel 已在做「轉身煞車塵」 |
| 跑步在 DL1 | 初代《夢之泉》前的 Dream Land 1 **沒有跑步**，是 Adventure 之後才有 | [慣例] | 不影響本作 |

**給 player-feel 的可實作結論**：跑步是「輸入技巧」不是「速度曲線」，所以起跑要有明顯的瞬間加速 + 身體前傾幀（`kirby_run`），不要做成線性 accel，否則玩家感受不到自己「觸發」了跑步。

### 1.2 漂浮（Hover / Float）— 最關鍵的一條
| 項目 | 原作行為 | 來源 |
|---|---|---|
| 觸發 | 空中再按跳躍鍵 → 吸一口氣鼓起 | [源] Wikibooks |
| **次數上限** | **大多數作品沒有次數上限，也沒有高度上限**。卡比可以無限次拍動、一路飛到關卡頂端，直到自己吐氣為止 | [源] WiKirby "Hover"：「Kirby can remain in the air indefinitely, until he releases an Air Bullet」 |
| 例外 | 只有《Kirby 64》與《Forgotten Land》會「累」而緩緩下降 | [源] WiKirby "Hover" |
| 上升方式 | 每按一次跳 = 一次拍動 + 一段上升；連按可持續爬升 | [源] Wikibooks |
| 結束方式 | 按攻擊鍵吐氣（Air Bullet），**吐氣後立刻變回一般下落狀態**，無法接著再漂浮（要重新起跳） | [源] Wikibooks / WiKirby "Air Bullet" |
| 吐氣傷害 | Air Bullet 會造成傷害；後期作品中**距離越近傷害越高** | [源] WiKirby "Air Bullet" |
| 漂浮時能做什麼 | 只能移動與吐氣，**不能使用複製能力**（能力招式需先落地或先解除漂浮） | [慣例] |
| 天花板 | 撞到天花板會停止上升但維持漂浮 | [慣例] |

**給 player-feel 的可實作結論（重要）**：
- 本作 SPEC 的漂浮參數（按跳 -1.6、重力 0.06、落速 0.8）方向正確，**不要加次數上限**，那會破壞卡比手感的核心（「玩家永遠不會因為飛不上去而卡關」正是卡比系列的入門友善設計）。
- 必做：**每按一次跳 = 一個明顯的「鼓起→拍動」幀**，讓連按有節奏感（目前 TASKS 已列）。
- 必做：**吐氣後短暫（建議 8~12 幀 [本作]）不能再進入漂浮**，否則玩家會用「吐氣→立刻漂浮」當成免費攻擊循環。
- 吐氣彈的傷害建議 **近距離 2 / 遠距離 1** [本作]，並在 ~64px 後消失。

### 1.3 滑鏟（Slide）
| 項目 | 行為 | 來源 |
|---|---|---|
| 輸入 | 蹲下（↓）+ 跳躍 | [慣例]（本作說明.md 已採用） |
| 效果 | 低姿態衝刺，撞到敵人造成傷害；可鑽過 1 格高縫隙 | [慣例] |
| 取消 | 《Super Star》起可用跳躍取消滑鏟 | [慣例] |
| 無能力時的主力 | 沒有複製能力時，滑鏟是唯一的近戰手段 | [慣例] |

**本作建議**：滑鏟 3.0 × 22 幀（現況）保留；補上 TASKS 已列的「跳躍取消」「撞牆回彈」。撞牆回彈建議 vx 反向 × 0.4、給 6 幀硬直 [本作]。

### 1.4 防禦（Guard）— 《Super Star》新增
| 項目 | 行為 | 來源 |
|---|---|---|
| 輸入 | 按住 L / R（SNES） | [慣例] |
| 效果 | **弱攻擊完全無傷；強攻擊減傷**（不是無敵） | [源] Kirby Wiki "Guard"：「reduces damage from stronger attacks and generally negates damage from weaker attacks」 |
| 破綻 | 對「抓取類」招式無效 | [源] 同上 |
| 姿勢 | 卡比縮成防禦姿態，無法移動 | [慣例] |
| 衍生 | 防禦 + 方向 = 閃避翻滾（Dodge），《Super Star》有 | [慣例] |

**本作建議 [本作]**：
- 優先度中。若要做，綁 `down` 長按或新鍵 `C`；規則：`damage <= 1` → 0 傷；`damage >= 2` → 減半（無條件捨去，最少 1）；防禦時 vx 歸零、不能攻擊、**不會掉能力**。
- 這條「防禦時不掉能力」是給玩家的正回饋，也讓魔王戰有第二種解法，建議一定要有。

### 1.5 吸入（Inhale）
| 項目 | 行為 | 來源 |
|---|---|---|
| 輸入 | 按住攻擊鍵 | [源] Wikibooks |
| 吸入範圍 | 身前一個扇形／矩形風區，約 **2.5~3 格寬（40~48px）**，離越近吸力越強 | [慣例] |
| 吸入時能否移動 | **可以左右緩慢移動**（明顯比走路慢），也可以轉身；**不能跳** | [慣例] |
| 持續時間 | 可一直按住，無上限；鬆開即停 | [源] Wikibooks |
| 吸到東西後 | 進入「含物（mouthful）」狀態：**身體變大、移動變慢、可以走可以跳、不能漂浮、不能滑鏟** | [慣例] + [本作 SPEC 已定含物走 1.0] |
| 吐出 | 再按攻擊 → 吐出星星彈（Star Bullet），直線飛行，可破星星方塊、打敵人 | [源] Wikibooks |
| 吞下 | 按 ↓ → 吞下取得複製能力（若該敵人有能力） | [源] Wikibooks |

**本作建議 [本作]**：
- 吸入移動速度 = 走路的 **45%（約 0.6 px/f）**，並保留轉身能力 —— 這是「吸入時能微調位置」的關鍵手感。
- 吸入風區用粒子表現（TASKS 已列），敵人進入風區要**被往卡比方向拉 + 抖動**，而不是瞬間消失。
- 星星彈傷害建議 **2**、射程 ~96px、可穿過 1 個敵人後消失 [本作]。
- **吸到東西的瞬間給 2 幀 hit-stop**（TASKS 已列）——這是整個吸入手感最划算的一筆投資。

### 1.6 受傷 / 能力掉落 / 能力星回收
| 項目 | 行為 | 來源 |
|---|---|---|
| 受傷掉能力 | 受傷時**有機率**（非必定）掉落目前能力；某些招式用太多次也會掉 | [源] WiKirby "Copy"：「lose copy abilities by occasionally taking damage or using them too many times」 |
| 能力星 | 掉落後變成「能力星」在場上**彈跳** | [源] 同上 |
| 回收方式 | **再吸一次**（或直接碰到，視作品）即可拿回 | [源] 同上 |
| 存在時間 | 彈跳一段時間後消失（原作未給精確幀數） | [慣例] |
| 主動丟棄 | 玩家可主動丟棄能力，同樣變成能力星 | [慣例]（本作已有，engine_test PASS） |

**本作建議 [本作]（給 player-feel / abilities-enemies）**：
- 掉落機率：**HP > 2 時 35%，HP ≤ 2 時 0%**（快死了不再懲罰，降低挫折）。
- 能力星參數：初速 `vx = ±1.2, vy = -2.4`，重力 0.18，彈跳保留 0.5 速度。
- **存在 300 幀（5 秒）**，最後 90 幀開始閃爍提示即將消失。
- 回收：**碰觸即回收**（本作已是這樣，engine_test `regain ability by touching star` PASS），比原作的「再吸一次」更寬鬆，適合本作只有一顆攻擊鍵的配置。
- 受傷無敵 90 幀（現況）合理；建議無敵期間能力星仍可回收。

## 2. 暫停畫面與能力說明卡

### 2.1 原作做法
| 作品 | 暫停畫面做法 | 來源 |
|---|---|---|
| 《夢之泉の物語 / Kirby's Adventure》 | 暫停**不是把音樂靜音而是降低音量**；暫停選單有**一頁以上**的說明，內容是目前角色的招式表 + **風味文字（flavour text）** | [源] WiKirby "Pause" |
| 《Super Star》 | 沿用並擴充：帶著複製能力暫停時，會顯示**該能力的簡短說明 + 怎麼用**（招式與輸入） | [源] WiKirby "Copy Ability"：「while using a Copy Ability, the pause screen contains a brief description of the ability and how to use it」 |
| 《新星同盟 / Star Allies》 | 魔王戰前有**介紹卡（introduction card）**：魔王名稱 + 上方一行短描述 | [源] Kirby Wiki / WiKirby |
| 系列共通 | 暫停說明是卡比系列的招牌，玩家用它來「發現自己會什麼招」；文案幽默、第三人稱、常用驚嘆號 | [慣例] |

### 2.2 風味文字的寫法（**必須自行創作，不得抄原作文案**）
原作的語氣特徵（可模仿語氣、不可抄字句）[慣例]：
- 第三人稱稱呼主角，語氣輕快、像繪本旁白。
- 一句話點出「這個能力是什麼感覺」，而不是條列數值。
- 常帶一個小玩笑或擬聲詞。

本作自創範例（**可直接採用，是我方原創文案**）[本作]：
| 能力 | 風味文字（繁中，建議 ≤ 18 字／行，最多 2 行） |
|---|---|
| 火焰 | 「呼——！吐出滾燙的火舌。小心別把草原烤焦了。」 |
| 劍 | 「握緊了就別鬆手。揮下去的瞬間，風都讓路。」 |
| 光束 | 「甩出一串閃亮的光鞭，啪嚓啪嚓地掃過去。」 |
| 刀刃 | 「丟出去、繞一圈、再接住。丟不準？再練練。」 |
| 電擊 | 「全身劈哩啪啦。靠太近的傢伙自己負責。」 |
| 石頭 | 「碰！變成一塊沉甸甸的石頭。這時候誰也推不動。」 |
| 冰凍 | 「一口冷氣把對手凍成冰塊，然後——踢出去！」 |

| 無能力 | 「深呼吸，把敵人吸進嘴裡吧！按 ↓ 吞下去就能偷走他的本事。」 |

### 2.4 給 ui-menu 的硬性規格 [本作]
1. 卡片寬 240、左右各留 8px；內距 8px；圓角不做（像素風用 1px 白框 + 1px 陰影）。
2. **中文一律 ≥ 14px**。本次 QA 實測（見 QA_REPORT）：12px 中文在 Linux 上完全糊成一團，14~16px 才勉強可讀。招式表右欄若放不下，**改用 8×8 ASCII 的英文名 + 中文只放在標題列**。
3. 招式表**最多 5 列**，超過就分頁（← → 翻頁），不要縮字。
4. 暫停時音樂降到 30%（audio agent 已在做）——這正是原作《夢之泉》的做法 [源]，值得保留。
5. 選單項目順序建議：`繼續 / 操作說明 / 能力說明 / 音量 / 回到地圖 / 回到標題`（TASKS 已列）。

| 具體門檻範例 | ① 星星方塊後面有暗門，**上面兩塊綠磚只有 Hammer 打得掉**；② 一組十字形方塊多出一塊，**把那塊打掉後走到該點就會進入暗門** [源] StrategyWiki |

**給本作的可行版本 [本作]**：
- 每個世界 **1 個大星星開關**（TASKS 已列「每世界 3 個隱藏收集品」→ 建議改成 **3 個大星星 + 1 個開關**，開關解鎖該世界的秘密房）。
- **隱藏房的三種門檻**（每個世界各用一種，不要重複）：
  1. **可破壞牆**：一段看起來和普通牆一樣的磁磚，打到就碎（給視覺微差：少一顆鉚釘）。
  2. **需要特定能力**：硬磚只有 Hammer 打得破 / 導火線只有 Fire 點得著 / 暗房只有 Spark 照得亮。
  3. **隱形門**：走到某個看似無意義的平台頂端 + 按 ↑。前面一定要放一個「提示物」（一排點數星指向它），**絕不能毫無線索**。
- **博物館房**：本作值得抄的機制。在每個世界的第 2~3 房放一個小房間，裡面站 2 隻不會動也不傷人的敵人（給不同能力），讓玩家換能力再挑戰魔王。成本極低、體驗提升極大。

每世界 3 個大星星，分配成固定的難度階梯：
| # | 類型 | 比例 | 說明 |
|---|---|---|---|

### 4.4 中魔王房的門鎖規則 [慣例]
系列慣例（原作未給條文，以下是通行做法）：
1. 卡比走進房間 → **鏡頭鎖定**、左右兩側的門「喀」一聲上鎖（門上出現鎖頭圖）。
2. 中魔王從畫面外登場（掉下來 / 走進來），有 60~90 幀的登場演出，**期間玩家不能動**。
3. 打倒後：門鎖解除 + **中魔王掉落對應的能力星**（這是中魔王存在的主要意義——給玩家一個指定能力）。
4. 若玩家死亡重來，中魔王重生。

**給本作的實作規格 [本作]（給 levels-bosses，TASKS 已列「中魔王房前奏演出」）**：
- `doors[].locked = true`，在 `room.midboss` 被擊敗時設 false。
- 登場演出 **75 幀**：0~15 鏡頭鎖定 + 門鎖動畫；15~60 中魔王入場；60~75 名字卡淡入淡出。演出期間 `KB.player` 輸入忽略。
- 本作已有 `mrfrosty` 與 w5 的「雙小魔王之間」，只要補門鎖與演出即可。
- **掉落能力星是必做的**：w5 的雙小魔王應分別掉 Ice 與 Hammer，讓玩家能選擇帶哪個去打迪迪迪。

### 4.5 魔王多階段設計 [慣例 + 本作實測]

- 魔王 HP 降到約 **50%** 時進入第二階段：變色（或表情變兇）、**新增 1~2 招**、既有招式的間隔縮短、移動變快。

### 5.2 給本作的可行版本與優先順序 [本作]

**標題選單（給 ui-menu，TASKS 已列）— 優先度 P0**
```
        KIRBY  STAR
      ---------------
        繼續遊戲        ← 有存檔才顯示，反白在最上
        新的遊戲
        操作說明
```

**優先順序（投報率由高到低）**
| 順位 | 項目 | 理由 | 負責 |
|---|---|---|---|

| 2 | 暫停能力卡 | 讓 8 種能力的新招「被看見」，不然做了也沒人知道 | ui-menu |
| 3 | 選關畫面顯示 ★ x/3 與最佳分數 | 收集品要有展示處才有意義 | ui-menu + levels-bosses |
| 4 | **競技場（Boss Rush）** | 用現成的 5 個魔王，幾乎零新美術，卻能讓遊玩時數翻倍 | levels-bosses |
| 5 | Extra Mode | 同樣零新素材（改 HP 與敵人密度即可） | levels-bosses |
| 6 | 100% 獎勵 | 收尾用 | 總控 |

**競技場規格建議 [本作]**
- 解鎖條件：**通關全 5 世界**（不要綁 15 顆星，太硬）。
- 規則：**1 條命**；依序打 5 個魔王（whispywoods → lololo → kracko → metaknight → dedede）。
- 開場讓玩家**自選 1 個能力**（照 Super Star）。
- 每場之間進休息房，放 **3 顆番茄**（照 Star Allies 的「休息區」概念，但數量按本作 HP 6 調整）；番茄用掉就沒了，**總共只有 3 顆**，這就是難度來源。
- 記錄最佳通關時間存 `KB.save.arena.bestTime`。

**Extra Mode 規格建議 [本作]**
- 解鎖條件：通關全 5 世界（與競技場同時解鎖，或通關後再多一步）。
- 差異（照原作精神，只調參數不做新關）：
  1. **卡比 HP 6 → 3**。
  2. 敵人 HP ×1.5、傷害 ×1.5。
  3. 魔王直接從第二階段開始（若已實作二階段）。
  4. 食物道具數量減半。
- 通關獎勵：解鎖「聽音樂」模式 + 標題畫面加一顆星星裝飾。

**100% 完成度定義建議 [本作]**
`5 世界通關 + 15 顆大星星 + 競技場通關 + Extra Mode 通關` → 標題畫面顯示 **100%** 與特殊稱號（自創，**不要用「Super Star」這種原作稱號**）。

| **音樂** | 重編官方旋律（即使是自己合成的音色） | **旋律必須完全原創**。「聽起來像卡比」要靠**調性與編制**（大調、五聲音階、明亮方波 + 跳躍貝斯），不要靠旋律動機 |
| **字型** | 使用官方遊戲的點陣字 | 自己畫 8×8 點陣字（現況 `src/art/font.js` 已是自畫） |
| **說明文案** | 翻譯原作的暫停說明文字 | 自己寫（本文 2.2 的風味文字皆為本專案原創，可直接使用） |

### 6.3 建議的處理順序
1. **（高）** 把 5 個魔王與 25 種敵人的名稱全部換成原創名 —— 這是最大風險，也是改動成本最低的（只動字串）。→ 建議由總控統一發一張對照表給 levels-bosses / abilities-enemies。
2. **（高）** 遊戲標題與主角名改成不含 "Kirby" 的原創名。
3. **（中）** 主角配色／輪廓加入 1~2 個原創辨識點。
4. **（低）** 石頭變身造型、關卡名微調。
5. 保持 `說明.md` 的免責聲明，並在標題畫面保留「同人作品」字樣（現況已有）。
