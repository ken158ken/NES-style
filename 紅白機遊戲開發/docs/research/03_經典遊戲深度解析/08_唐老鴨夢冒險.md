# 08 唐老鴨夢冒險（DuckTales / ダックテイルズ，1989）

## 摘要（10 行內）
1. Capcom 1989 年 10 月在北美推出的迪士尼授權平台遊戲，是「洛克人工廠」外包給版權作的代表作。[源]
2. **稲船敬二的首次執導**（此前只掛角色設計），製作人藤原得郎，團隊大量來自《洛克人》。[源]
3. 核心機制 **拐杖彈跳（Pogo Jump）**：空中按 ↓ + B 進入彈跳姿勢，持續按住 B 就能一直彈——同時是移動、攻擊與探索工具。[源]
4. **五個關卡可任意順序挑戰**（亞馬遜、外西凡尼亞、非洲礦坑、喜馬拉雅、月球），沿用洛克人的選關結構。[源]
5. **軟性關卡門檻**：非洲礦坑需要外西凡尼亞的「骷髏鑰匙」，月球需要「UFO 鑰匙」與「遙控器」——用道具而非數字鎖住順序。[源]
6. 錢＝分數＝結局條件：**三種結局**（普通 / 最佳需 $10,000,000 + 兩件隱藏寶物 / 最差需 $0）。[源]
7. **Launchpad McQuack 同時是檢查點與「離開關卡」的傳送門**，且離開後可重進同一關讓寶物重新出現——刷錢機制被寫進設計。[源]
8. 初始 3 點生命，兩個隱藏的 Life Extender 可永久提升到 **5 點**。[源]
9. 音樂由外村博茂（Hiroshige Tonomura）創作，**月球關主題曲**是 8-bit 音樂史上最知名的曲子之一。[源]
10. NES 版銷量約 **167 萬套**，是 Capcom 該平台最暢銷的作品之一。[源]

## ② 核心迴圈與操作

### 按鍵配置 [源：StrategyWiki / Controls]
| 按鍵 | 功能 |
|---|---|
| ←→ | 移動 |
| ↑ / ↓（在繩索上） | 上 / 下攀爬 |
| ↓ | 蹲下 |
| A | 跳；在繩索上按 A = 放手 |
| **B** | 揮拐杖：把可移動物件（石塊、寶箱、保險箱）**當高爾夫球打出去** |
| **↓ + B（空中），然後按住 B** | **拐杖彈跳（Pogo Jump）**；按住不放就持續彈跳 |
| Start | 暫停 |
| **Select（關卡中）** | 隱藏指令：**花 $3,000,000 完全回復血量**（說明書未載） |

### 拐杖彈跳的三重用途（本作的設計核心）
1. **攻擊**：從上方彈在敵人頭上即擊殺；等於把「踩敵」變成一個需要持續維持的姿勢。
2. **移動**：彈跳可越過尖刺、在某些表面（岩石、彈簧物）上彈得更高，是唯一能到達高處的手段。
3. **探索**：大量寶石是**隱形的**，只有「跳過去碰到」才會顯現；所以「一路彈跳前進」既是最快也是最賺的走法。[源]

> **一個動作同時服務三個系統（戰鬥 / 移動 / 收集）**，這是 DuckTales 設計上最高明的地方。[推論]

### 彈跳高度控制
- 進入彈跳姿勢後若一直按住 B，會以**最大高度**持續彈跳。
- 若想控制高度：在想要的高度放開 B、再立刻按下 B 續彈。[源]

### 生命與計時
| 項目 | 內容 |
|---|---|
| 初始生命點 | **3 點**（Easy 難度為「兩次受傷才扣 1 點」） |
| 上限 | 收集兩個 **Life Extender** 後為 **5 點** |
| 每關開始 | 生命點**重置為滿** |
| 即死 | 掉出畫面下緣、計時歸零 |
| 計時 | 每關剩餘秒數在通關時換成 **每秒 $100** |

### 核心迴圈
`選關 → 一路彈跳前進（同時打怪、挖隱形寶石）→ 遇到 Launchpad（檢查點）→ 取得該關傳說寶藏 → 打魔王 → 回控制室 → 選下一關`
外加一個 **刷錢副迴圈**：`用 Launchpad 離開關卡 → 重新進入同一關 → 所有寶物重生 → 再刷一次`。[源]

### 獎勵關（Bonus Stage）
- 當**當前關卡已賺金額的「萬位數」為 7**（例如 $270,000）時請 Launchpad 帶你回都市，會先進入空中獎勵關。
- 畫面自動向左捲動，Gyro Gearloose 駕機在雲上投下藍鑽，**每顆 $10,000**。[源]
- 這是一個**隱藏在數字裡的觸發條件**，完全靠玩家 / 雜誌傳播發現。[推論]

## ⑤ 魔王設計

| 魔王 | 招式 | 弱點 / 破法 | 階段 |
|---|---|---|---|
| **Incan Sentinel**（亞馬遜） | 石像在房間內來回衝撞、跳躍 | 拐杖彈跳踩頭 | 單階段；教「魔王也用同一套彈跳打」 |
| **Magica DeSpell**（外西凡尼亞） | 瞬移 + 發射魔法彈，**變身成烏鴉閃避** | 在她現身的瞬間彈跳踩頭 | 單階段；教「等待現身窗口」 |
| **King Slime**（非洲礦坑） | 分裂 / 跳躍砸地，落地產生震波 | 彈跳踩頭；需在震波之間找立足點 | 單階段 |
| **Abominable Snowman**（喜馬拉雅） | 投擲雪球、大跳 | 彈跳踩頭；房間較窄 | 單階段 |
| **Moon Rat**（月球） | 高速移動 + 投射 | 彈跳踩頭 | 單階段 |
| **Dracula Duck**（終章） | 變形 + 召喚蝙蝠 + 多段攻擊 | 彈跳踩頭；為全作最高血量 | 最終魔王 |
| **Flintheart Glomgold 追逐**（終章結尾） | 不是戰鬥：**與對手競速爬繩索**搶中央石柱上的寶箱 | 純速度 | **非戰鬥的最終挑戰** |

### 設計觀察
- **所有魔王都用同一種攻略手段（彈跳踩頭）**。玩家不需要學新操作，只需要學新的「時機」。這對面向兒童的授權作是正確的選擇。[推論]
- 魔王 HP 明顯高於敵人，戰鬥是「連續成功 N 次同一個動作」的耐久測驗，而非組合技測驗。[推論]
- 最終挑戰不是打鬥而是**競速**，呼應「守財奴搶寶」的角色設定 —— 機制與主題一致。[推論]

| 結局 | 條件 |
|---|---|

| **最差** | 通關時總額 **$0**（需先把錢累積到 $3,000,000 的倍數，再用 Select 指令花光） |

## ⑦ 難度曲線與教學手法

1. **亞馬遜作為預設起點**：地形平坦、敵人慢、第一次跳躍就會撞出隱形鑽石 → 玩家在 10 秒內學會「要一直跳」。[源＋推論]
2. **地上 / 地下分岔是第一堂「風險 vs 報酬」課**：兩條路都通到同一處，但地下危險、寶物多。玩家第一次可能走上面，第二次就會走下面。[源]
3. **選關自由 + 道具門檻**：五關可任意選，但礦坑需要外西凡尼亞的鑰匙。玩家撞牆一次後自己推導出順序，不需要教學文字。[源]
4. **Launchpad 的雙重角色**：既是「再也不用重打前半段」的安全網，也是「主動離開去刷錢」的工具。**同一個 NPC 同時降低挫折與提高深度。**[推論]
5. **難度極低但深度很高**：主線約 40–60 分鐘即可完成，但要達成最佳結局需要理解隱形寶石、隱藏寶物、獎勵關觸發條件與刷錢路線。這是授權作面向兒童與核心玩家的雙軌設計。[推論]
6. **NPC 提示系統**：Huey / Dewey / Louie / Webby 散佈在關卡中提供提示，Mrs. Beakley 提供完全回血 —— 用角色取代說明文字。[源]
7. **生命點每關重置**：不會因為前一關打得糟而影響下一關，鼓勵玩家嘗試任意關卡順序。[源]

## ⑧ 技術亮點

1. **雙軸捲動 + 房間網路**：外西凡尼亞的鏡子傳送系統實際上是把關卡切成多個獨立區塊，以「傳送」取代連續地形，大幅降低關卡資料量。[推論]
2. **隱形物件系統**：寶石以「碰撞才顯現」的方式存在，本質上只是一張座標表 + 一個旗標，卻創造出整個探索層。**極高 CP 值的內容擴充手法。**[推論]
3. **彈跳姿勢的狀態機**：pogo 是一個獨立的玩家狀態，擁有自己的碰撞框（腳下有攻擊判定）與落地反彈邏輯；只多一個狀態就換來全新玩法。[推論]
4. **迪士尼角色的像素化**：Capcom 用 2×2 或 2×3 的 8×16 精靈拼出史高治，並以帽子 / 外套 / 拐杖三個高對比色塊維持辨識度 —— NES 3 色 + 透明的精靈調色盤限制下的標準解法。[推論]
5. **場景物件可被「打飛」**：石塊 / 寶箱 / 保險箱被揮杖擊出後變成飛行物件，可撞死敵人或撞開通路。用同一套物件系統兼做武器與機關。[源＋推論]
6. **Mapper 與容量待查**：本次查證未能取得權威 ROM 規格來源（Data Crystal 無對應條目、NesCartDB 受 Cloudflare 阻擋）。[待查]

## ⑨ 音樂音效特色

- 作曲：外村博茂（Hiroshige Tonomura），他在 Capcom 任職期間並不長，本作全部曲目皆由他創作。[源]
- **The Moon（月球主題）** 被公認遠比其他曲目複雜且原創，是 8-bit 音樂史上最常被翻奏 / 重編的曲子之一。[源]
- 風格：明亮的大調 + 高速琶音 + 強烈的貝斯 riff（三角波），與迪士尼卡通的輕快調性一致，但和聲比一般兒童向作品複雜得多。[推論]
- 每關一首主題曲 + 魔王曲 + 控制室曲 + 獎勵關曲，數量不多但辨識度極高。[推論]
- 音效與彈跳動作同步：拐杖敲擊地面的「叩」聲每次彈跳都會響，形成節拍器效果，讓玩家用聽覺掌握彈跳節奏。[推論]

## ⑩ 對原創遊戲的可借鑑清單（10 條）

1. **設計一個「一招三用」的核心動作**：彈跳同時是攻擊、移動與探索工具。若你只能做好一個機制，就讓它同時服務三個系統。
2. **隱形收集物**：寶物預設不可見，玩家「碰到」才顯現。只需一張座標表就能讓整張地圖值得重走一遍。
3. **選關自由 + 道具門檻**（礦坑需要別關的鑰匙）：用道具而非等級或數字鎖住順序，玩家撞牆一次就會自己推導。
4. **檢查點 NPC 同時是「主動離開關卡」的傳送門**：降低挫折與提供刷資源路線，一個角色做兩件事。
5. **讓貨幣同時是分數、結局條件與回血代價**：花 $3,000,000 回滿血，讓「要不要花錢」變成有意義的抉擇。
6. **三種結局用同一份內容分岔**：普通 / 最佳（需隱藏收集 + 金額門檻）/ 最差（需歸零），零額外關卡成本。
7. **所有魔王共用同一種攻略手段**，只改時機與場地。對輕度取向的遊戲來說，這比「每個魔王一套新規則」更友善。
8. **最終挑戰可以不是戰鬥**：以「競速搶寶箱」收尾，讓機制呼應主題。
9. **場景物件可被打飛並造成傷害**：一套物件系統兼做武器、機關與解謎工具。
10. **把提示交給 NPC 角色**（提示、回血、獎勵關），而不是介面文字；同時符合授權作的角色曝光需求。
