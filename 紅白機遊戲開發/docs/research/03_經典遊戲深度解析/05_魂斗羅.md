# 05 魂斗羅（Contra / 魂斗羅，1988）

## 摘要（10 行內）
1. Konami 1987 年街機作的家用移植，NES / FC 版 **1988 年 2 月**發售，由梅崎茂治與北本真治監督。[源]
2. FC 版使用 Konami 自製 **VRC2** mapper（有動畫背景與過場），海外 NES 版被迫改用任天堂標準的 **UNROM（mapper 2）**，ROM 容量砍半。[源]
3. PRG 128 KiB（1 Mbit），CHR-RAM；8 個關卡。[源]
4. **一擊即死**——沒有血條，把難度全部放在「站位與預判」。[源]
5. **兩人同時遊玩**是本作最大的商業武器；兩位玩家不會互相傷害。[源]
6. 關卡混用三種視角：橫向捲動、**縱向捲動（瀑布）**、**偽 3D 背面視角（基地）**，在同一片卡匣裡做出三種遊戲。[源]
7. 武器 6 種（M / L / F / S / R / B），其中 **Spread（S）** 因為單發威力等同機槍且一次 10 發，成為公認的最強解。[源]
8. **Konami Code（↑↑↓↓←→←→BA）在標題畫面可得 30 命**，是電玩史上最著名的作弊碼。[源]
9. NES 版銷量約 **200 萬套**。[源]
10. 3 條命 + 3 次 continue；第 4 次 continue 會從第 1 關重新開始。[源]

## ② 核心迴圈與操作

### 按鍵配置
| 按鍵 | 功能 |
|---|---|
| ←→ | 跑 |
| ↑ / ↗ / ↘ / ↓ | **八方向瞄準**（站立時可朝上、斜上、斜下；蹲下時只能水平） |
| ↓ + A | 從平台向下穿落 |
| A | 跳（前空翻；**固定高度、不可變高**） |
| B | 射擊（跳躍中亦可，且可八方向） |
| ↓（空中）+ B | 向正下方射擊 |
| Select（標題） | 1P / 2P 切換 |

### 手感規則
- **一擊死**：碰到敵人、子彈、爆炸都直接失去一條命；掉坑亦然。[源]
- **跳躍是翻滾動作**：起跳後角色蜷曲，判定框縮小；這是「跳躍＝迴避」的隱藏機制。[推論]
- 跳躍中可完全控制水平方向、可自由射擊 → 與惡魔城完全相反的哲學：**魂斗羅把空中變成主要戰場**。[推論]
- 蹲下可躲過多數水平彈幕；砲手（Gunner）連射 3 發後會停頓，就是留給玩家的移動窗口。[源]
- **武器不可切換、不可保留**：碰到新武器立刻替換，死亡一律退回初始步槍。[源]
- 每種武器有各自的**畫面內同時存在上限**：步槍 4、機槍 6、火球 4、散彈 10。這等於是隱形的 DPS 上限。[源]

### 核心迴圈
`前進 → 打掉武器感應器 / 空投膠囊取得武器 → 用武器碾過一段 → 魔王 → 死亡退回步槍 → 重新蒐集`

死亡的真正懲罰不是命數，而是 **武器歸零**。這讓「不死」本身成為玩家追求的目標。[推論]

## ③ 關卡結構

| # | 關卡 | 視角 / 捲動 | 魔王 |
|---|---|---|---|
| 1 | 叢林 Jungle | 橫向捲動；上下兩條路徑（橋 / 水面） | Jungle fortress（基地大門：兩座砲塔 + 中央核心） |
| 2 | 基地 1 Base 1 | **偽 3D 背面視角**，向畫面深處推進 | Terminal 1（**2 階段**） |
| 3 | 瀑布 Waterfall | **縱向捲動**（唯一一關往上爬） | Mechanical alien |
| 4 | 基地 2 Base 2 | 偽 3D 背面視角 | Terminal 2（**2 階段**） |
| 5 | 雪原 Snow Field | 橫向捲動；裝甲車 + 樹林手榴彈 | Anti-gravity shuttle（反重力梭） |
| 6 | 能量區 Energy Zone | 橫向捲動；**上中下三層 + 定時火焰噴口** | Armored Giant |
| 7 | 機庫 Hangar | 橫向捲動；**機械叉臂 + 尖刺牆 + 礦車** | Alien lair defense |
| 8 | 異形巢穴 Alien's Lair | 橫向捲動；生物質地形 | 子魔王：異形口器；最終：**Red Falcon（心臟 + 核心）** |

| 項目 | 內容 |
|---|---|
| 每關長度 | 約 90–180 秒 |
| 檢查點 | 每關數個；死亡從最近檢查點重生（但畫面不會回捲） |
| 續關 | 3 次；第 4 次從第 1 關開始 |
| 分支 | 第 1 關有「橋上 / 水中」兩條路（影響能否拿到 Spread）；其餘關卡多為上下兩層路線 |
| 密碼 / 存檔 | 無 |

### 偽 3D 基地關的規則（第 2、4 關）
- 畫面固定為「往深處看」的視角，玩家在畫面下緣左右移動、可跳。
- 必須打掉**電子牆上的核心**才會前進到下一個房間。
- 這是全作最特殊的段落：把橫向捲動射擊改成**房間清除（arena clear）**，節奏上提供對比。[推論]

## ④ 敵人設計（代表 10 種）

| # | 敵人 | 行為模式 | 教學意義 |
|---|---|---|---|
| 1 | 步兵 Soldier | 從畫面邊緣跑入、遇到落差會跳、偶爾開槍 | 教「持續湧入的壓力」，讓玩家一直保持前進 |
| 2 | 狙擊兵 Sniper | 原地不動、**瞄準精度高、可八方向射擊** | 教「先清遠程再推進」 |
| 3 | 潛水兵 Scuba Soldier | 從水中露頭、發射**空中分裂成三片的迫擊彈** | 教「有些敵人不值得殺，只要走開」 |
| 4 | 砲手 Gunner | 固定砲座；**連射 3 發後停頓** | 教「敵人的節奏就是你的窗口」；蹲下可完全躲過 |
| 5 | 牆面砲塔 Wall turret | 灰色方塊 + 旋轉砲管；**接近才啟動** | 教「觸發半徑」——可以繞過而不交戰 |
| 6 | 彈出式加農砲 Cannon | 進入射程才從地面彈出，只能水平射擊 | 教「蹲下 = 安全」的通用規則 |
| 7 | 地雷 Mines | 從基地房間深處緩慢滾向玩家 | 教「基地關的空間壓縮」 |
| 8 | 防衛機器人（白 / 紅） | 白色跳到地面攔截、紅色**留在上方干擾** | 教「分工型敵組」：一隻逼你移動、一隻懲罰你移動 |
| 9 | 浮游生物 Floater / 孢子 Spore | Floater 慢速漂向玩家；Spore 高速直線撲來 | 教「速度差」：慢的擋路、快的致命 |
| 10 | 機械叉臂 / 尖刺牆（第 7 關） | 固定週期上下的機械臂、從地面升起的尖刺牆 | 純機關敵人：教「觀察週期再通過」 |

## ⑤ 魔王設計

| 關 | 魔王 | 招式 | 弱點 | 階段 |
|---|---|---|---|---|
| 1 | Jungle fortress | 兩側砲塔拋出弧線爆裂彈；中央大門發射直線彈 | **先清掉兩側砲塔**，再打大門核心 | 單階段；教「優先目標」 |
| 2 | Terminal 1 | 階段 1：外殼旋轉護盾 + 彈幕；階段 2：護盾破後露出核心並加速射擊 | 核心 | **2 階段** |
| 3 | Mechanical alien | 瀑布頂端的機械體，發射散射彈與追蹤物 | 中央弱點；需在窄平台上維持站位 | 單階段（縱向場地） |
| 4 | Terminal 2 | 同 Terminal 1，但同時出現白 / 紅防衛機器人 | 核心 | **2 階段 + 雜兵干擾** |
| 5 | Anti-gravity shuttle | 反重力梭在畫面上方左右移動，向下投彈 | 機身下方開口 | 單階段；**必須邊跑邊打** |
| 6 | Armored Giant | 巨型機甲，拳擊 + 胸口砲 | 胸口核心 | 單階段 |
| 7 | Alien lair defense | 多組砲口同時發射，場地狹窄 | 逐一清除砲口 | 單階段 |
| 8 | 子魔王：異形口器 | 從天花板伸出，持續吐出 Floater | 貼牆向斜上射擊 | 前哨戰 |
| 8 | **Red Falcon** | 巨大心臟 + 兩側生成 Crawler 的孵化口 | 心臟（需持續輸出） | 最終戰；**沒有 Spread 幾乎打不完** |

### 設計觀察
- **魔王幾乎都是「靜止的建築物」而非會追你的生物**。這讓設計者能精確控制彈幕幾何，且省下大量精靈預算。[推論]
- 每個魔王都有「先做什麼」的正確順序（先砲塔、後核心），把魔王戰變成**優先權判斷題**。[推論]
- 兩人模式下魔王 HP 不變 → **雙人難度顯著下降**，這是刻意的社交設計。[推論]

## ⑥ 道具與成長

### 武器（同時只能持有 1 種）
| 代號 | 武器 | 特性 | 畫面上限 |
|---|---|---|---|
| （無） | 步槍 Rifle | 單發、按一下射一發；**每次重生退回此武器** | 4 發 |
| **M** | 機槍 Machine Gun | 按住 B 連射、子彈快 | 6 發 |
| **L** | 雷射 Laser | **單發威力最高**但最慢；**射新的會取消舊的**；可貫穿 | — |
| **F** | 火球 Fire | 螺旋前進，上下擺動範圍大、速度慢 | 4 發 |
| **S** | 散彈 Spread | 扇形多發；**每發威力＝機槍一發**，近距離全中≈雷射 | 10 發 |
| **R** | Rapid | **提升所有武器射速**（雷射除外），可與武器疊加 | — |
| **B** | Barrier | 約 20 秒無敵；接觸步兵即殺，但對載具 / 重砲無效；掉坑仍死 | — |
| Falcon | 鷹徽 | 清除畫面上所有基本敵人（對機械無效），**觸碰即發動** | — |

### 取得方式
- **武器感應器**（地面 / 牆上的裝置）：射擊後掉出武器。
- **空投膠囊**：從畫面一側飛過，需在飛出畫面前擊落。
- 兩者都要求玩家**主動花時間去打**，而不是走過去撿 → 武器是「換來的」不是「給的」。[推論]

### 成長曲線
- **沒有永久成長**。玩家唯一的累積是「記憶」與「命數」。
- 命數：初始 3 條；Konami Code 給 30 條。得分達到特定門檻也會加命。[源]

## ⑦ 難度曲線與教學手法

1. **第 1 關的 30 秒教學**：出生在左側高台 → 掉進水裡不會死（教「水不是坑」）→ 第一個狙擊兵（教瞄準）→ 武器感應器給機槍（教「打裝置有獎勵」）→ 空投膠囊給 Rapid（教「會飛的也要打」）→ 爆炸橋（教跳躍時機）。[源]
2. **兩條路線教「選擇」**：第 1 關橋上路線能拿到 Spread，水中路線拿不到。玩家第二次玩會自己找上面那條。[源]
3. **關卡類型交替**：橫 → 偽 3D → 縱 → 偽 3D → 橫 → 橫 → 橫 → 橫。前四關刻意把三種視角全部展示完，之後才進入純橫向的高難度段。[推論]
4. **一擊死 + 檢查點密集**：懲罰極重但重試極快（通常 5–15 秒），維持「再來一次」的節奏。[推論]
5. **難度來自彈幕密度而非敵人智力**：第 6、7 關把「定時機關 + 遠程敵人 + 窄平台」三者疊加，玩家必須同時管理三個週期。[推論]
6. **Konami Code 是官方認可的難度選項**：開發者留下 30 命，等於承認「這遊戲對家用機玩家太難」。[推論]
7. **雙人模式是最有效的難度調節器**：兩人互相吸引火力、互相復活（共用命數池以外的心理支撐）。[推論]

## ⑧ 技術亮點

1. **三種視角共存於 1 Mbit**：橫向捲動、縱向捲動、偽 3D 房間三套渲染邏輯塞在同一份 128 KiB ROM。[源]
2. **偽 3D 的作法**：不是真的 3D，而是把背景畫成透視格線並**逐層縮放捲動**，角色維持固定大小只能左右移動。以極低成本製造縱深。[推論]
3. **CHR-RAM 換來的視覺多樣性**：UNROM 沒有 CHR-ROM bank 切換，全部圖形在關卡載入時寫入 CHR-RAM，所以每關可以有完全不同的圖塊集。[源]
4. **爆炸與煙霧的精靈重用**：所有爆炸共用同一組 4 幀動畫，只是換調色盤與縮放位置。[推論]
5. **雙人時的精靈壓力管理**：兩個玩家 + 各自子彈（最多 10 發散彈 ×2）+ 敵人，遠超過 64 個精靈上限，所以本作有明顯且**刻意保留的閃爍**——Konami 選擇閃爍而非消失，確保子彈永遠可見。[推論]
6. **VRC2 → UNROM 的降級取捨**：FC 版的動畫背景與關間過場在 NES 版被移除，換來更便宜的板子；但關卡與玩法完全保留。這是「先保住玩法、再談表現」的經典取捨。[源]

## ⑨ 音樂音效特色

- 作曲：前澤秀憲、佐田清宏。[源]
- **Jungle Theme（第 1 關）** 是 NES 時代辨識度最高的曲子之一：快速的 16 分音符貝斯（三角波）+ 兩支脈衝波做軍樂式的號角動機。
- 節奏設計刻意配合「持續前進」：全曲幾乎沒有留白，BPM 高、每 8 小節就有一次和聲推進。[推論]
- 基地關（Base）使用低音域與半音階，與叢林關形成明顯對比，**用音樂標示「視角改變」**。[推論]
- 音效優先權：射擊音（噪音 / 脈衝波）極短促，避免長時間搶佔旋律聲道；爆炸用噪音聲道的長包絡。[推論]
- FC 版因為 VRC2 板的差異，部分音色與 NES 版不同。[源]

## ⑩ 對原創遊戲的可借鑑清單（10 條）

1. **一擊死 + 密集檢查點**：重生間隔控制在 5–15 秒內，死亡的成本就從「挫折」變成「節奏」。
2. **死亡的真正懲罰是武器歸零**，而不是進度歸零。讓玩家為了「保住火力」而小心，比為了「保住命」更有效。
3. **每種武器設畫面內同時存在上限**（4 / 6 / 10 發），用這個數字而不是傷害值來做平衡。
4. **八方向射擊 + 跳躍中可射擊**：如果遊戲以射擊為主，就把空中變成主要戰場，跳躍時縮小判定框當作隱藏的迴避獎勵。
5. **武器要用「打」來換而不是用「走」來撿**：感應器要射擊、空投要擊落，讓取得本身就是一次小挑戰。
6. **魔王做成「靜止的建築 + 多個部位」**：先打側翼、再打核心，把魔王戰變成優先權判斷題，精靈預算也省一半。
7. **關卡視角輪替**（橫 / 縱 / 房間清除）：前四關把所有玩法類型展示完，之後才進入高難度純化段落。
8. **第一關就給兩條路，其中一條有更好的武器**：玩家第二輪自然會去探索，不需要任何文字提示。
9. **雙人同時遊玩是最便宜的難度調節器**：不改任何數值，只要允許兩人同場，難度就降一半、樂趣加倍。
10. **內建一個「官方作弊碼」**：與其把難度調低，不如留一個入口（30 命）給挫折的玩家，同時保留原本的硬派設計。
