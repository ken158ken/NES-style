# 10 銀河戰士 Metroid（1986）深度解析

## 摘要（10 行內）
1. 1986-08-06 日本 Famicom Disk System 首發，1987-08 北美 NES、1988-01-15 歐洲。[源]
2. 任天堂 R&D1 + Intelligent Systems 開發，製作人橫井軍平，導演岡田智／山本正夫，音樂田中宏和。[源]
3. NES 版為 **MMC1、128 KB ROM**，用 **24 字密碼**（144 bits：128 資料 + 8 檢查碼 + 8 位移）取代 FDS 的磁片存檔。[源]
4. 開創「探索型動作」（後稱 Metroidvania）：能力道具即地圖鑰匙，地圖是一張互相纏繞的網。[源]
5. 五大區：Brinstar、Norfair、Kraid 巢穴、Ridley 巢穴、Tourian；電梯是分區與載入的界線。[源]
6. **遊戲內沒有地圖**——原始設計預期玩家自己畫方格紙地圖。[源]
7. 通關時間決定結局（<1h 最佳），是最早的「時間評價 + 多結局」之一。[源]
8. 音樂由田中宏和刻意反旋律化：「想做出讓玩家覺得在遭遇一個活體生物的配樂」。[源]
9. 女主角 Samus Aran 的性別在結局才揭曉，成為 8-bit 時代最有名的敘事翻轉。[源]
10. 至 2004 年全球銷量約 **273 萬套**。[源]

**密碼系統細節**：144 bits = 128 bits 遊戲狀態 + 8 bits 檢查碼 + 8 bits 位移量；以 6 bits 為單位切成 24 個字元，對應自訂的 64 字元表；位移量會把 128 bits 整串旋轉，使同一狀態能產生多種合法密碼（也讓亂猜幾乎不可能）。[源]

## ② 核心迴圈與操作

**核心迴圈**：進入未知房間 → 掃描地形／敵人 → 嘗試現有能力（射擊、球化、炸彈）→ 發現「打不開的地方」→ 記在腦中的地圖 → 找到新能力 → **回頭**打開先前記下的所有節點。

**操作**
- 左右移動、跳躍（可控高度）、射擊（可朝上）、蹲下＝球化（取得 Maru Mari 後）。
- **不能邊蹲邊射、不能斜射**：射擊只有水平與正上方，這個限制決定了所有敵人的移動路線設計（很多敵人走地板或天花板，逼你調整站位）。[推論]
- 球化 + 炸彈是探索的萬用工具：通過矮通道、炸開地板、原地跳（bomb jump 為後續作品的基礎）。[源/推論]
- **無地圖**、無定位點、無傳送，只有電梯。方向感全靠玩家記憶與手繪地圖。[源]

## ③ 世界／關卡結構

### 分區

| 區域 | 定位 | 特徵 |
|---|---|---|
| Brinstar | 起點／中樞 | 綠色植被調色盤，難度低，通往各方向 |
| Norfair | 熔岩區 | 高傷害地形，逼玩家先拿 Varia Suit／High Jump |
| Kraid 巢穴 | 支線魔王區 | 進入後結構封閉，打完拿獎勵 |
| Ridley 巢穴 | 支線魔王區 | 同上，兩隻魔王可任意順序 |
| Tourian | 終局區 | Metroid 群 + Mother Brain + 逃脫倒數 |

- 進入 Tourian 需**同時擊敗 Kraid 與 Ridley**，兩座雕像亮起後開路——經典的「兩把鑰匙開一道門」非線性結構。[源]
- 地圖採「垂直與水平混合捲動」：MMC1 能切換 nametable 鏡射方向，讓遊戲在縱向豎井與橫向長廊之間切換。[源]
- 房間資料以格子拼貼（structures / rooms 重用）大量複製，是 128 KB 內塞下大地圖的關鍵，但也造成「畫面長得很像、容易迷路」的著名缺點。[源/推論]
- **Secret Worlds（祕密世界）**：卡在門裡的 Door Jump 漏洞能讓玩家跑進正常遊玩區外的地圖資料，看到一堆亂碼地形——本質是「地圖資料沒有邊界檢查」的副作用，卻成了玩家社群的傳說。[源]

### 引導與迷路對策（以現代眼光檢討）
- 正向：電梯＝區域分隔記憶點；每區用**單一主色調色盤**建立方位感；能力道具通常放在死路盡頭，讓「死路」變成獎勵而非挫折。[推論]
- 負向：房間重用度過高、沒有地圖、沒有標記已探索、回頭路長且無捷徑——這是後續《Super Metroid》加入地圖系統與捷徑門的直接原因。[源/推論]

## ④ 系統數值

| 項目 | 數值 | 標記 |
|---|---|---|
| 起始能量 | 99 | [源/推論] |
| Energy Tank | 每個 +100 上限；**全地圖 8 個、最多帶 6 個** | [源] |
| Missile Tank | 每個 +5 上限，最多 255 發 | [源] |
| 魔王獎勵 | 擊敗 Kraid／Ridley 各給大量飛彈（合計可達 150） | [源] |
| 回復方式 | **只能打敵人掉落**（能量球／飛彈），無回復點 | [源] |
| 結局門檻 | <1h / 1–3h / 3–5h / 5–10h / >10h 共 5 種 | [源] |

**設計觀察**
- 死亡後復活只給 **30 能量**（不是滿血），於是「打小怪補血」成為常態迴圈——這是本作最被詬病也最具時代特徵的節奏。[源/推論]
- 能量上限（6 tank = 699）與飛彈上限（255）之間，飛彈是「對魔王的硬通貨」，能量是「對地形的耐受度」，兩者成長曲線分工清楚。[推論]
- 時間結局把「效率」變成隱藏難度層，等於在沒有計分板的動作遊戲裡植入速通文化。[源/推論]

## ⑤ 敵人設計

| 敵人 | 行為 | 教學目的 |
|---|---|---|
| Zoomer | 沿地面／天花板爬行，不追蹤 | 地形即威脅；學會「跳過去而不是打」 |
| Skree | 從天花板俯衝並爆炸 | 抬頭看天花板 |
| Rio / Waver | 空中波形移動 | 水平射擊的角度限制 |
| Ripper | 直線來回、**多數武器打不死** | 有些敵人是「會動的平台」（用 Ice Beam 凍成踏板） |
| Sidehopper | 大跳躍、高傷害 | Norfair 的難度宣告 |
| Rinka | 從牆壁不斷生成的能量環 | 在 Mother Brain 戰中變成可凍結的踏板 |
| Metroid | 吸附吸血，**只有 Ice Beam + 飛彈能解** | 全遊戲最大的「機制考題」 |

**關鍵設計**：Ice Beam 同時是武器、是解謎工具（凍結敵人當踏板）、也是通關必需品。**一個道具兼三種功能**是 Metroid 最值得抄的設計。[源/推論]

## ⑥ 魔王／高潮設計

- **Kraid / Ridley**：兩隻可任意順序挑戰的中魔王，打法都是「站定位、卡在對方攻擊死角、用飛彈輸出」。它們的真正功能是**門鎖**（點亮雕像）。[源/推論]
- **Mother Brain（Tourian）**：不是傳統一對一。房間裡有 5 座 **Zebetite** 屏障、Rinka 生成器、砲台與熔岩池；必須先用飛彈逐一轟掉 Zebetite，再打玻璃管中的大腦。[源]
- **逃脫倒數**：擊破後啟動倒數（999），必須沿原路殺回電梯——把「已經走過的路」在最後一刻重新變成高張力關卡，零新美術成本製造高潮。[源]
- **結局揭曉**：Samus 脫下動力裝甲，揭露她是女性；速通者還能解鎖更多結局變體。[源]

## ⑦ 道具／成長

| 道具 | 功能 | 類型 |
|---|---|---|
| Maru Mari（球化） | 變成小球通過矮通道 | 通行權 |
| Bombs | 球化狀態放炸彈，炸地板／敵人 | 通行權 + 攻擊 |
| Long Beam | 子彈射程延長到整個畫面 | 手感改善 |
| Ice Beam | 凍結敵人（可當踏板）；打 Metroid 必需 | 武器 + 解謎 + 必需品 |
| Wave Beam | 波形彈道、可穿地形 | 火力（但與 Ice 互斥，需取捨） |
| High Jump Boots | 跳更高 | 通行權 |
| Varia Suit | 受傷減半 | 耐受度 |
| Screw Attack | 翻滾跳躍時無敵殺傷 | 移動 + 攻擊 |

**成長邏輯**
- 沒有等級、沒有經驗值，成長全部來自「找到東西」；**每一件道具都會改寫地圖的可達性**。[推論]
- Ice Beam 與 Wave Beam **不能同時裝備**（撿到後者會覆蓋前者），造成真正的取捨——現代作品多半取消這點，但作為設計工具值得保留思考。[源/推論]
- NES 版 New Game+：破關後再開，保留能力但不保留 Tank，且優秀結局會沿用無裝甲造型。[源]

## ⑧ 難度曲線與教學

- 開場房間：一條短走廊 + 一個必經的矮通道 → 你在第一分鐘就會被迫理解「球化」的存在（道具就在右邊死路）。[推論]
- 教學完全靠**空間**，沒有文字；但代價是有人卡在第一個 Morph Ball 就放棄——這是「零文字教學」的風險示範。[推論]
- 難度階梯：Brinstar（低傷害敵人）→ Norfair（地形傷害 + 高跳需求）→ 魔王巢穴（密集戰鬥）→ Tourian（Metroid 群 + 資源耗盡壓力）。[推論]
- 死亡懲罰：回到該區入口、能量只剩 30 → 實質懲罰是「補血磨時間」而不是「重打關卡」。[源/推論]
- 密碼制的副作用：密碼記錄狀態但**不記錄遊戲時間**，所以用密碼續關者會拿到特定結局分支（與時間判定互動）。[源/推論]

## ⑨ 技術亮點

1. **MMC1 的鏡射切換**：同一款遊戲同時支援橫向與縱向捲動區段，讓「豎井 + 長廊」的立體地圖在 NES 上成立。[源]
2. **128 KB 塞下五大區**：靠房間拼貼重用與高度壓縮的地圖資料，代價是視覺重複感。[源/推論]
3. **密碼即存檔**：144 bits 的位元打包 + 檢查碼 + 位移混淆，是 8-bit 時代「沒有電池也要有長進度」的教科書解法。[源]
4. **電梯＝載入遮罩**：切區時的電梯動畫掩蓋圖塊／資料切換，是低成本的無縫感手法。[推論]
5. **地圖資料無邊界**造成的 Secret Worlds，反過來證明當年資料驅動關卡的做法有多輕量。[源]

## ⑩ 音樂音效特色

- 田中宏和明確反對當時「琅琅上口的流行小調」路線，主張音樂要服務氣氛：他說想做出「**讓玩家覺得自己正在遭遇一個活體生物**」的配樂。[源]
- 他也追求「**音樂與音效之間沒有界線**」：環境噪音、脈動低音、金屬敲擊與敵人音效被寫成同一套聲音語言。[源]
- Brinstar 主題是少數有明確旋律的曲子（作為「安全區」的標記）；Norfair 與 Tourian 走無調性、持續音與噪音通道。[推論]
- Item Fanfare（取得道具的短句）與 Escape 倒數曲：兩者都用「音樂事件」標記玩法狀態變化。[源/推論]
- 這種做法對「電子音樂像素遊戲」極具參考性：**把環境音當作曲的一部分**，比多寫一首主題曲更能塑造世界。[推論]

## ⑪ 對原創遊戲的可借鑑清單（10 條）

1. **能力即鑰匙（ability-gating）**：用「球化／高跳／凍結」等動詞切割地圖，玩家的成長體現為地圖的展開。
2. **一物三用**：像 Ice Beam 那樣讓關鍵道具同時是武器、平台工具與魔王解法，遠比多給三個單功能道具划算。
3. **死路即獎勵**：把道具放在死路盡頭，讓玩家願意探索沒有出口的分支。
4. **區域色彩學**：每區一套調色盤與一套敵人，讓玩家用顏色記方位（低成本的認知地圖）。
5. **兩把鑰匙開一門**：允許任意順序完成的兩條支線，非線性感高但流程可控。
6. **回頭路變高潮**：終局倒數逃脫，讓熟悉的路在壓力下重新變成關卡。
7. **時間評價多結局**：以通關時間分層結局，等於免費附贈速通模式與重玩動機。
8. **密碼／短存檔字串**：若走瀏覽器或 ROM 路線，位元打包 + 檢查碼的密碼制既懷舊又能當作分享機制（可把密碼做成可貼給朋友的 URL）。
9. **必須修正的地方**：**一定要給地圖**（或探索標記）。Metroid 的迷路痛點是後續 Metroidvania 全面加入地圖與捷徑的原因。
10. **音樂當氣氛層**：主旋律只給「安全區」，危險區改用脈動、噪音與環境音——電子音樂風格天生適合這種分層。
