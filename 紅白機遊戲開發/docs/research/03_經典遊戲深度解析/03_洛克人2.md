# 03 洛克人 2（Mega Man 2 / ロックマン2 Dr.ワイリーの謎，1988）

## 摘要（10 行內）
1. Capcom 1988-12-24 推出，是「非線性選關 + 武器剋制」結構的定型之作。[源]
2. 初代銷量不佳，製作人藤原得郎反對續作；監督北村玲自行爭取許可，團隊在**同時進行其他專案**的情況下用 3–4 個月、每日近 20 小時做完。[源]
3. 向玩家公開徵集魔王設計，收到 **8,370 件投稿**，是系列首次導入玩家共創。[源]
4. Mapper **MMC1**，PRG 256 KiB（2 Mbit），CHR 使用 CHR-RAM（0 CHR-ROM）。[源]
5. 新增 **E 罐（Energy Tank）** 與 **密碼系統**，直接回應初代「太難、無法中斷」的批評。[源]
6. 西方版新增 **Normal 難度：所有特殊武器傷害 ×2**；日版只有相當於 Difficult 的數值。[源]
7. 8 魔王 + 8 武器構成完整剋制環；`Metal Blade` 過強（對 Metal Man 自身 14 點傷害）成為系列平衡的經典反面教材。[源]
8. 全球銷量約 151 萬套，是 2019 年《洛克人 11》之前系列最暢銷作。[源]
9. 立石孝（Takashi Tateishi）配樂受 Mezzoforte 與 YMO 影響，是 NES 音樂史上被翻奏最多的作品之一。[源]
10. Wily 4 的 **Boobeam Trap 需要恰好 7 發 Crash Bomber**，是「資源型魔王」的極端案例（也是知名設計爭議）。[源]

## ② 核心迴圈與操作

### 按鍵配置
| 按鍵 | 功能 |
|---|---|
| ←→ | 走（無跑步鍵，速度恆定） |
| ↑↓ | 爬梯 |
| A | 跳（**可變高度**：放開即減速上升） |
| B | 射擊 / 使用特殊武器 |
| ↑ / ↓ + B | `Metal Blade` 八方向、`Atomic Fire` 蓄力（按住 B） |
| Select | 開啟武器選單（**暫停畫面即武器切換**） |
| Start | 暫停 |

### 手感規則
- **沒有加速度**：按下方向鍵立即達到定速，放開立即停止。這讓平台跳躍完全可預測 —— 與瑪利歐的「慣性手感」是兩種截然不同的設計哲學。[源：遊戲行為]
- 水平速度約 **1.375 px/frame**（社群量測值；官方無公開數據）。[推論]
- 空中可完全轉向、可完全控制水平移動（無空中慣性）。[源：遊戲行為]
- 跳躍高度可變：按住 A 跳滿約 **3.5 格磚（56 px）**，點一下約 1 格。[推論]
- **P 射擊上限 3 發**：畫面上同時最多 3 顆普通子彈。[源]
- **受傷 = 強制後退（knockback）+ 短暫無敵**；後退距離足以把玩家推下懸崖，這是本作最主要的致死原因。[源：遊戲行為]
- **梯子規則**：爬梯時可射擊（面向固定）、按 A 可直接鬆手落下、梯頂需完整爬出才算落地。
- 特殊武器耗能：每支武器 28 格能量，`Metal Blade` 每發耗 0.25 格（＝可發 112 次），`Atomic Fire` 全蓄力一次耗 10 格。[推論：社群量測]

### 核心迴圈
`選關 → 闖關（平台 + 敵人）→ 打魔王 → 取得武器 → 用新武器讓下一關更輕鬆 → 重複 8 次 → Wily 要塞`

這是一個 **玩家自訂難度曲線** 的迴圈：先打誰完全由玩家決定，選錯順序＝全程用 Mega Buster 硬打。[推論]

## ③ 關卡結構

| 項目 | 內容 |
|---|---|
| 魔王關 | 8 關（可任意順序） |
| Wily 要塞 | 6 關（線性、必須依序） |
| 總關數 | 14 |
| 每關長度 | 約 2–5 分鐘；由數十個「螢幕」（256×240 的畫面單位）串成 |
| 捲動 | 水平為主；**以畫面為單位切換（screen transition）**，捲到邊界時畫面整頁推進 |
| 房間 | 每個畫面即一個房間；敵人在畫面進入時生成、離開時銷毀 |
| 檢查點 | 每關 2–3 個；死亡回到最近的畫面邊界 |
| 密碼 | 5×5 格點陣，記錄「已擊敗的魔王」與「E 罐數量」 |
| 續關 | 無限 continue，從該關檢查點重來 |

### 8 個魔王關的結構特徵
| 關卡 | 核心機制 |
|---|---|
| Metal Man | 輸送帶（改變玩家移動方向）+ 大量小型敵 |
| Air Man | 雲朵平台（會移動 / 消失）+ 上升氣流 |
| Bubble Man | 水中物理（跳更高、落更慢）+ **天花板尖刺即死** |
| Quick Man | **雷射光束（碰到即死）** + 需背板的高速下降 |
| Crash Man | 垂直向上爬升的塔 + 密集平台 |
| Flash Man | 冰面 + 需 `Crash Bomber` 打開的牆 |
| Heat Man | **消失磚（Yoku Block）** 的節奏跳躍 + 岩漿 |
| Wood Man | 森林 / 犬型敵 + 落葉 |

### 分支與祕密
- 關卡本身**線性**，但有需要特定武器才能取得的 **E 罐與 1-UP**（如 `Item-1/2/3` 到達的高處、`Crash Bomber` 炸開的牆）。[源]
- Quick Man 關的雷射區可用 `Time Stopper` 全部凍結（唯一解或硬背板）。[源]

## ⑥ 道具與成長

| 道具 | 效果 |
|---|---|
| **E 罐（Energy Tank）** | 隨時把血量補滿；最多攜帶 4 個；密碼會記錄數量 |
| 小 / 大 能量球 | 回復血量（藍）或武器能量（橘） |
| 1-UP | 加命 |
| **Item-1** | 召喚向上升的踏板（垂直移動） |
| **Item-2** | 噴射雪橇（水平長距離移動） |
| **Item-3** | 貼牆向上爬的踏板 |

- `Item-1/2/3` 由 Wily 要塞前的三個特定魔王掉落（Heat Man / Air Man / Flash Man），是「移動能力＝鑰匙」的設計：**能力不只用來戰鬥，也用來開路**。[源]
- **沒有經驗值、沒有等級**。成長 100% 來自「玩家獲得的工具」與「玩家自己的技術」。[推論]
- 密碼只記錄「已打倒哪些魔王 + E 罐數」，不記錄命數與武器能量 → **刻意讓玩家每次續關都是滿武器**。[源]

## ⑦ 難度曲線與教學手法

1. **選關畫面就是難度選單**：8 關難度天差地遠（Metal Man 最易、Quick Man 最難），玩家用 Mega Buster 試錯後自然收斂出順序。[推論]
2. **每關第一個房間都是「安全教室」**：例如 Heat Man 關開場是一段平坦地面 + 單隻敵人，讓玩家熟悉武器；Yoku Block 段落一定在有立足點的地方先出現一次短版。[推論]
3. **武器剋制環 = 內建的難度遞減機制**：每打贏一關，下一關就變簡單一階。玩家的「挫折」與「進展」被系統保證交替出現。[推論]
4. **E 罐作為玩家自控的難度閥**：存 4 罐就能硬闖；這是把「要不要降低難度」的決定權交給玩家。[源]
5. **Boobeam Trap 的反面教材**：需要精準資源規劃、且沒有任何提示，玩家只能靠死亡學習。現代設計應避免「唯一解 + 不可逆資源」。[推論]
6. **Wily 要塞是綜合考**：把 8 關教過的所有機制（消失磚、輸送帶、雷射、水中）重新組合，並在 W5 加上 **Boss Rush（8 魔王重打）**。[源]
7. **無限 continue**：懲罰只在時間，不在進度 → 支撐了極高的關卡難度。[源]

## ⑧ 技術亮點

1. **CHR-RAM 而非 CHR-ROM**：圖形在關卡載入時從 PRG 解壓到 RAM，使得每關可以有完全不同的圖塊組，而不需塞下 128 KiB 的 CHR-ROM。[源：Data Crystal 標示 0 × 8 KiB CHR-ROM]
2. **畫面單位捲動（screen-based）**：關卡以「畫面」為單位切換而非連續捲動，大幅簡化 nametable 管理，也讓敵人生成邏輯變得單純（進畫面才生成）。[推論]
3. **武器選單畫面**：暫停時整個畫面重繪成選單，利用「遊戲暫停 = PPU 可自由寫入」的空檔，不需額外硬體。[推論]
4. **精靈閃爍（flicker）作為設計選擇**：Capcom 選擇讓超過 8 sprite/scanline 的物件輪流顯示（閃爍）而非消失，保證玩家仍能看到威脅。[推論]
5. **Wily 1 的巨龍**：用多個 16×16 精靈拼成大型 boss，並以背景捲動偽裝移動。[推論]
6. **密碼系統用 5×5 = 25 bit** 編碼 8 個魔王旗標 + E 罐計數，是極省 RAM 的存檔替代方案。[源]

## ⑨ 音樂音效特色

- 作曲：立石孝，靈感來自冰島爵士融合團 **Mezzoforte** 與 **YMO（Yellow Magic Orchestra）**。[源]
- 編制：脈衝波 1 = 主旋律（常用快速琶音與顫音）、脈衝波 2 = 對位 / 和聲、三角波 = 貝斯線（本作的貝斯線特別旋律化）、噪音 = 鼓。[推論]
- **Wily Stage 1** 與 **Air Man Stage** 是 chiptune 史上被翻奏最多的曲目之一；前者的和聲進行被大量「nerd rock」樂團引用。[源]
- 音效設計上，特殊武器各有專屬音色，玩家換武器後「聽得出來」自己拿的是什麼。[推論]
- 受傷音與死亡爆炸（8 個對稱飛散的能量球 + 特有音效）成為系列標誌。[推論]

## ⑩ 對原創遊戲的可借鑑清單（10 條）

1. **選關表 = 難度選單**：給 6–8 個可任意順序的關卡，難度差距拉到 3 倍以上，讓玩家自己找路。
2. **武器剋制環**：N 個魔王、N 把武器，每把武器對 1 位魔王造成 **5–14 倍於基礎武器的傷害**（弱點 2–3 發秒殺，基礎武器需 28 發）。
3. **魔王 HP 統一為 28**，只調整傷害倍率——平衡只需維護一張 N×N 的表格。
4. **不要有加速度**：若遊戲以精準平台跳躍為核心，就讓移動「按下即全速、放開即停」，跳躍才可能做到像素級可預測。
5. **受傷不扣命而是把玩家推開**：knockback 距離設在「足以推下一格寬平台」的量級，讓地形本身成為傷害放大器。
6. **武器 = 鑰匙**：至少 3 種能力同時具備「戰鬥用途」與「開路用途」（升降板、噴射、爬牆）。
7. **給玩家一個可囤積的救命資源（E 罐，上限 4）**，並且讓它出現在需要繞路才能拿到的位置。
8. **密碼只存「進度旗標 + 消耗品數」**，不存武器能量與命數，讓每次續關都乾淨。
9. **消失磚（Yoku Block）**：純節拍型平台是最便宜的高難度內容——一個週期計數器就能做出整個段落，但務必先在安全處示範一次。
10. **避免「唯一解 + 不可逆資源」的魔王**（Boobeam Trap 教訓）：若魔王需要特定彈藥，就必須在場內提供補給，或允許玩家重試而不損失進度。
