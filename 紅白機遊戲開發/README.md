# 紅白機遊戲開發（研究與開發基地）

> 本資料夾為**個人學習用**的技術研究筆記，不含任何 ROM 或受版權保護的遊戲資料；所有素材原創、不營利。完整聲明見 [../DISCLAIMER.md](../DISCLAIMER.md)。

> 與 `../卡比之星` 平行的獨立專案。**目標（2026-09-14 定調）：用現代程式（Canvas + Web Audio）把紅白機的畫面 / 手感 / 聲音「原汁原味」還原**——不做卡帶、不做 ROM；引擎層就套用 PPU / APU 的限制（25 色、每線 8 精靈、2A03 五聲道），手感採研究的反組譯數字。素材原創。
> 實作計畫見 `docs/PLAN.md`；研究文件是規格來源。

## 原則
- 所有內容以繁體中文撰寫，引用要附網址（Wikipedia / NESdev Wiki / 官方 / 開發者訪談）。
- 區分「事實（有來源）」與「推論 / 建議」。
- 未來開發的美術、音樂、關卡一律原創，不使用任何版權 ROM / 圖片 / 音訊。
